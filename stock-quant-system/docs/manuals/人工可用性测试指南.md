- **测**：打开、看懂、走通「录入持仓 → 生成建议 → 对照图表/风险/复盘」；字够不够大；乱输入会不会崩。

## 3. 逐页 + 边界

### 3.1 掘金扫描

- [ ] 滑块=10 运行一次；滑块=200 再运行一次，两次都出表
- [ ] 表头是中文
- [ ] ❓ RankIC / ❓ 因子能弹出解释

### 3.2 行情图表

- [ ] 已持有代码或公司名：有 K 线；持仓票应有成本/止损/止盈虚线
- [ ] 输入 `999999`：提示没有行情，不崩溃

### 3.3 风险仪表盘

- [ ] 集中度是 **水平柱**，不是饼图；纵轴是股票代码（或「代码 名称」），**不能**出现「60万」这种市值刻度
- [ ] 柱上有百分比；有「15%上限」红虚线；超过 15% 的柱为红色；图下方有对照表
- [ ] 单票 >15% 时顶部红警告
- [ ] ❓ 集中度、❓ VaR、❓ 最大回撤能弹出

### 3.4 AI 解释

- [ ] 真实代码（如 000001 或首页候选）：左侧有结构化数据；右侧若已配千问，中文说明里 **不应** 出现「建议买入/立刻满仓」，也 **不应** 出现 `removeChild` / 「未找到错误」红框
- [ ] 左侧「系统日历日期（今天）」应是本机当天（例如 2026-08-26），**不能**写成 2024；新闻行应带 `[发布时间]`，不能只有「08-21」这种无年份标题让模型自己补年
- [ ] 右侧解释 **不应** 把「今天/当前」说成 2024 年（模型训练记忆停在旧年份是正常的，靠本机日期注入纠正，不是断网，也不是要换 DeepSeek）
- [ ] `abcdef` 或 `000000`：不崩溃
- [ ] 没配 Key：黄条，左侧数字还在

### 3.5 名词解释

- [ ] 无搜索词时有术语卡片
- [ ] 搜 `xyz123`：空列表，页面不崩
- [ ] 搜 `VaR` 或 `回撤`：能命中

### 3.6 历史建议复盘

- [ ] 生成过建议后有记录；名称 **不是** 字面 `nan`
- [ ] 筛选器清空全部：提示「没有符合当前筛选条件的记录」
- [ ] ❓ 置信度能弹出

## 5. 请勿当成新 bug

| 现象 | 原因 |
|------|------|
| 建议日期不是日历今天 | 用最近已入库交易日 |
| AI 解释提到 2024 / 像「断网」 | 聊天模型没有时钟；已注入本机日期。换 DeepSeek 不能对时 |
| 扫描前列很多北交所 | 已知小盘偏好，当观察名单 |
| 生成建议要等几十秒 | 全市场打分 |
| 启动器弹出黑窗口 | 日志窗口，关掉应用会停 |
| 换电脑 exe 双击没用 | exe 不含 Python，先装 `.venv` |
| 控制台 `use_container_width` | Streamlit 弃用警告，功能仍正常 |
