## 3. 对照结论（压缩版）

完整表见规格文档 §5–§6。对「完整散户链」最关键的几条：

**已经能帮上忙的**

- 选出一批相对排序靠前的股票（掘金扫描 + 涨跌停/停牌过滤）  
- 按账户状态出动作：止损 / 减仓 / 止盈 / 持有 / 观望 / 建仓意向  
- 集中度 15% 超限会建议减仓  
- 行为冲突提示（不改排名）  
- 大白话卡片 + 参考止盈止损价  
- 建议留痕与简化复盘  

**效用落差（用户会觉得「还不能拿去下单」）**

- `open` 文案仍是「仓位大小自己把控」——对照代码 `advice/advice_engine.py` `_plain_summary`  
- 无股数、无金额、无「买不起 1 手则 watch」  
- 无本机模拟成交（T+1 / 100 股 / 费用）  
- 无明日待办（信号日 ≠ 执行日）  
- 复盘不对照成交价，也不含仓位与费用  
- 无现金账户，1 万约束里的「现金 ≥10%、最多 2–3 只」无法闭环  

Must 粗计：19 项中 **已落地 2**（M1 扫描冠军、M18 事实上不因浮亏加仓），**部分落地 7**，**未做 10**。Should 多数未做或半成品。Won’t 保持干净。

## 4. 调研如何改了计划（不是另起炉灶）

外部证据（上交所/清华账户研究、理性指数、深交所 2020 问卷、知乎/Reddit 社区；**X 检索失败未引用**）与理论库同向：

- 小账户亏在选股 **和** 择时 **和** 费用，不是单点「预测不准」  
- 仓位与退出计划比再多一个因子更致命  
- 择时模块不能按「能择时赚钱」验收  

因此规格相对对接文档只做了这些微调：补 **以损定仓**、把 **禁止浮亏加仓** 写成 Must、择时验收改口径、频率熔断降优先级。阶段顺序仍是 A→B→C→D。
