## 1. 用户输入 → 名词拆解

### 1.1 分析维度类

| 用户词 | 拆解 | 行业常用近义 | 学术/理论锚点 |
|--------|------|--------------|---------------|
| 产业面 | 产业链、行业景气、竞争格局、产能/政策 | 行业分析、中观研究 | 产业组织、景气周期、波特五力（实务化） |
| 概念 | A股「题材/主题」；亦指抽象金融概念 | 主题投资、概念炒作、事件驱动 | 注意力资产定价、叙事经济学、拥挤交易 |
| 交易与市场盘 | 盘口、成交、委托簿、分时、微观供需 | 盘口分析、订单流、市场微观结构 | Market microstructure、Order flow |
| 心理学 | 投资者认知与情绪偏差 | 交易心理、情绪周期 | 行为金融学 |
| 博弈 | 多空/主力-散户/信息优势方互动 | 主力博弈、博弈论读盘 | Game theory、信息不对称、Kyle 模型 |
| 量化交易 | 规则化/模型化下单与研究 | 程序化、系统化交易 | Quant investing、统计套利、因子投资 |

### 1.2 技术指标类

| 用户词 | 全称/含义 | 指标族 | 平级应补 |
|--------|-----------|--------|----------|
| 成交量 | Volume；量价关系 | 量价 | OBV、VWAP、换手率、量比、VR |
| KDJ | 随机指标 | 摆动/超买超卖 | Stoch、RSI、WR、CCI、BIAS |
| RSI | 相对强弱指数 | 摆动 | 同上；另区分 **RS 相对强度**（≠RSI） |
| WR | Williams %R 威廉指标 | 摆动 | 同上 |
| DMI | 动向/趋向指标（+DI/-DI/ADX） | 趋势强度 | MACD、MA、ADX 单列、SAR |
| CCI | 顺势/商品通道指标 | 偏离/摆动 | BIAS、布林带位置 |
| BIAS | 乖离率 | 偏离均线 | CCI、布林 %B |

### 1.3 仓位与绩效类

| 用户词 | 拆解 | 类别 | 平级应补 |
|--------|------|------|----------|
| 暗盘 | ①港股新股暗盘；②口语/软件「暗盘资金」类盘口代理指标（非官方术语） | 微观结构 / 制度 | 集合竞价、盘后固收、暗池 Dark Pool、冰山单 |
| 暗仓 | 隐藏持仓意图；冰山单/暗池成交；非公开建仓 | 微观结构 / 信息隐藏 | 对倒、洗盘、吸筹派发 |
| 调仓 | 再平衡；主动调整权重 | 组合管理 | 再平衡、换手、漂移、税收感知调仓 |
| 最大回撤 | Max Drawdown | 绩效/风险 | 回撤持续期、水下时间、Ulcer Index |
| 波动率 | Volatility（历史/隐含） | 风险 | ATR、已实现波动、GARCH 预测波动 |
| 夏普比率 | Sharpe Ratio | 风险调整收益 | Sortino、Calmar、Information Ratio、Omega |

### 1.4 场景类（决策问题）

| 场景 | 核心问题 | 理论工具包 |
|------|----------|------------|
| 大盘跌、个股仍涨，卖不卖？ | 相对强弱 vs 补跌风险；持仓逻辑是否仍成立 | RS/Alpha、Beta、行业中性、止盈规则 |
| 行业突破/概念火热，买还是抛？ | 催化真实性、拥挤度、估值、阶段（启动/高潮/退潮） | 主题生命周期、事件研究、注意力溢价 |
| 大额买 + 小额卖，风险与操盘？ | 订单流真伪、对倒/吸筹/派发识别 | 微观结构、操纵手法分类、合规红线 |
