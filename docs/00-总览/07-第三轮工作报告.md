# 第三轮工作报告：方法架构补齐 · 权威性核验 · 全项目对齐

> 本报告对应用户指令："先再看一下行业成熟方法、模型训练方式和原理、架构和相关知识，补齐，然后进行理论库权威性和真实性验证，再做全项目对齐，最后给出工作报告。"

## 1. 任务拆解与执行顺序

```text
阶段一：方法与架构补齐（研究 + 落库）
阶段二：权威性与真实性核验（抽查关键数字/公式，标注来源与置信度，修正错误）
阶段三：全项目对齐（交叉引用、目录结构、索引YAML一致性自动化核查与修复）
阶段四：本报告
```

## 2. 阶段一：方法与架构补齐

### 2.1 诊断结论

此前的量化方法章节（`03-量化方法/00`–`05`）覆盖了因子投研、经典 ML/DL 结构罗列、回测框架，但缺少三类关键内容：**如何正确训练与验证模型的方法论细节**、**前沿架构的选型依据与已知工程陷阱**、**模型上线后的工程治理**。这三类恰恰是"行业成熟方法"与"玩具项目"的分水岭。

### 2.2 新增 5 篇专章（`03-量化方法/10`–`14`）

| 文档 | 核心内容 | 关键来源锚点 |
|------|----------|--------------|
| `10-时序验证与标签工程.md` | 三重障碍标注法、元标签（Meta-Labeling）、Purged K-Fold + Embargo、Combinatorial Purged CV、Walk-Forward | Marcos López de Prado《Advances in Financial Machine Learning》(2018)，金融机器学习领域公认奠基著作 |
| `11-深度学习前沿架构详解.md` | TCN/PatchTST/N-BEATS/TimesNet/TFT/Informer 选型地图、TFT 五组件拆解与已知梯度塌陷陷阱、GNN关系建模（GCN/GraphSAGE/GAT/GATs_ts/RSR/TGC） | Google TFT 原始论文、华泰金工GNN选股研报、公开工程实测报告（含TFT在金融数据上的失败模式实证） |
| `12-强化学习与决策类方法.md` | DQN/PPO/DDPG/Decision Transformer、GNN+RL感知决策一体化架构、奖励设计陷阱、离线RL与仿真环境 | 公开量化工程案例、RL交易学术综述 |

### 2.3 明确的能力边界标注（诚实性优先）

- TFT在金融数据上的已知不稳定性（输出层梯度塌陷）已作为陷阱明确写入，而非只呈现论文的漂亮指标  
- RL、扩散模型市场生成、LLM多智能体均标注为 **research/前沿** 成熟度，并在产品启示中明确"不建议作为面向普通用户的首发功能"  
- GNN选股的历史回测超额数据明确标注"历史结果不代表未来表现，需在自有样本重新验证"  

## 3. 阶段二：权威性与真实性核验

### 3.1 核验方法

由于全库已达 80 篇文档，逐句核验不现实，采用**风险分级抽查**策略：优先核验"具体数字/阈值/制度性规定"（易过时、易出错、影响产品合规），对"教科书级公式"（CAPM、Sharpe、DCF等）判定为学术共识、低风险，不重复核验。

### 3.2 发现并修正的问题（共5处实质性修正）

| 问题 | 修正前 | 修正后 | 来源 |
|------|--------|--------|------|
| 主板ST/\*ST涨跌幅 | 文档写5% | **10%**（2026-07-06新规生效，与主板普通股一致） | 沪深北交易所2026-04-24发布的交易规则修订公告 |
| 退市财务类"组合退"营收门槛 | 笼统写"低于某阈值" | **主板3亿元、创业板/科创板1亿元、北交所5000万元**（2024年4月修订，主板由1亿元上调至3亿元） | 深交所《股票上市规则》修订说明PDF |

### 3.3 未发现问题、维持原状的核心公式类内容（举例，判定为高置信度）

CAPM/Fama-French/APT 定价公式、夏普/索提诺/卡玛比率定义、VaR/CVaR定义、DCF/DDM/EVA核心公式、杜邦三因子分解、三重障碍标注法与Purged K-Fold流程——均为学术界/业界公开共识内容，且已在原文中标注方法出处（如López de Prado著作），判定为**高置信度**，未做改动。

### 3.4 保留"以最新规则为准"式免责表述的合理性

对涨跌幅、退市指标等制度性数字，本轮虽已更新为核验后的最新值，但**保留了"具体以交易所公告为准"的提示语**——因为如本轮核验所发现的（ST涨跌幅在3个月内从5%调整到10%），A股交易制度变动频率较高，任何静态文档都存在过时风险，这是有意的工程设计而非疏漏。

| Markdown 方括号链接 `[text](path)` | 同上 | **0 处失效** |
| YAML 索引（taxonomy/models/scenarios/tools/competitors）中的 `docs:` 路径引用 | 正则提取 + 文件存在性校验 | **0 处失效** |
| 孤立文档（未被任何其他文档/README/YAML引用的文件） | 全文语料库频次统计 | 发现1处（`01-基础概念/01-证券市场基础.md`），**已修复**：在阅读路线图与投资流派总览中补充引用 |

## 7. 遗留边界与建议

- 本库仍是**背调与理论沉淀成果**，不包含实盘代码；权威性核验解决的是"文字表述是否准确"，不能替代产品上线前对接真实数据源/监管公告的实时核验流程
