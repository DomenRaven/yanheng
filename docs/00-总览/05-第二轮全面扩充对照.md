# 第二轮全面扩充对照（深度与广度）

> 背景：第一轮名词补齐（见 `04-本轮名词拆解与补齐对照.md`）验证了"按用户提问查漏"的方法有效，但也暴露出理论库在**没有被直接问到的方向**上仍有大量结构性空白。本轮不再等待具体提问，而是主动对全库做一次系统性体检，覆盖专业股票研究/量化投研应涉及的主要知识域。

## 1. 诊断方法

1. 罗列一个成熟"股票研究+量化"知识体系应覆盖的顶层知识域清单（估值、技术理论、衍生品、宏观配置、量化深化、风险深化、投资流派、制度）  
2. 逐一对照现有 46 篇文档，标记「完全缺失 / 仅提及未展开 / 已充分覆盖」  
3. 对「缺失」与「仅提及」的域，先联网调研权威资料，再落库，并为每个新领域同步补齐其子概念与平级概念（不是补一个词，补一整片）

## 4. 仍然明确排除或降权处理的方向（边界重申）

- 高频交易/做市商实盘架构：仅作背景知识科普，不作为个人产品功能（门槛与合规限制）  
- 场外配资：明确列为风险提示对象而非可用工具  
- 财务造假的确定性断言：只做"红旗计数"概率性提示，不做法律定性  
- 波浪理论/缠论等主观性强的理论：要求先规则化、可回测化才能产品化，不能直接作为"感觉数浪"式建议输出
