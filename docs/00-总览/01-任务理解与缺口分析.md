# 任务理解与缺口分析

## 1. 你原始目标（复述）

做一个**辅助炒股**产品，核心能力包括：

- 股票**预测**与**量化**
- 按**不同场景 / 不同阶段**给出专业建议：购入/购出、加仓/减仓、风险评估等
- 自身金融专业度不足，需要先做全面、专业的背调，并补全理解偏差

这一定位在行业里更接近：**投研辅助决策系统（Decision Support）**，而不是「保证赚钱的荐股机器人」。

---

## 2. 行业先进产品真正在做的事

成熟量化/智能投研产品通常是一条闭环，而不是单点「预测股价」：

```text
数据（量价/基本面/另类）
  → 特征/因子工程
  → 信号（Alpha / 预测）
  → 组合构建与约束优化
  → 风险预算与仓位
  → 交易成本与可交易性
  → 回测 / 样本外 / 压力测试
  → 归因与监控（Alpha 衰减、风格漂移）
  → 场景化建议（解释 + 置信度 + 行动边界）
```

国际侧：Bloomberg Terminal + ASKB、FactSet Quant、QuantConnect LEAN。  
国内侧：聚宽 / 米筐 RQ 系列 / 同花顺 SuperMind / 东方财富 / 雪球。  
学术与工程：Microsoft Qlib、多因子 + Barra 风险模型、Transformer/GNN/LLM-Alpha 等。

## 3. 你方案中容易缺失或理解偏差的点

### 3.1 「预测」≠「交易决策」

| 常见误解 | 更正确的理解 |
|----------|--------------|
| 预测涨跌就能赚钱 | 预测只是信号；收益取决于仓位、成本、风控、制度约束 |
| 模型准确率越高越好 | 交易更关心排序能力（IC/RankIC）、超额与回撤，而非分类准确率 |
| 给出买卖点即可 | 必须同时给出：**仓位大小、持有期、失效条件、最坏情景** |

### 3.2 「建议」必须场景化与可解释

同一标的在不同阶段建议完全不同，例如：

- 空仓建仓 vs 已有浮盈加仓 vs 浮亏补仓（补仓往往是高风险行为）
- 趋势突破 vs 均值回归震荡
- 高波动/流动性差 vs 蓝筹高流动性
- 个人风险承受度、资金期限、集中度约束不同

先进产品会输出：**建议动作 + 理由链路 + 不确定性区间 + 不建议情形**。

### 3.3 A 股硬约束被严重低估

- **T+1**：当日买入不可卖出，短线策略与美股逻辑不同  
- **涨跌停 / 停牌**：信号可能不可执行  
- **交易成本与冲击成本**：散户双边成本不可忽略  
- **程序化交易监管（2024–2025）**：报备、异常交易监控、高频认定标准等  
- **智能投顾/荐股合规边界**：未持牌产品应定位为「工具/教育/自助分析」，避免承诺收益与代客决策

### 3.4 回测陷阱（产品若不防，一定会翻车）

- 前视偏差（Look-ahead）、幸存者偏差、未来函数  
- 过拟合与参数偷窥（Multiple testing）  
- 忽略滑点、停牌、涨跌停无法成交  
- 样本内漂亮、样本外崩塌；风格切换导致因子失效（Alpha Decay）

### 3.5 「专业建议引擎」缺的一层：账户状态机

专业加减仓不是孤立信号，而是基于**账户状态**的策略：

- 现金比例、单票/行业集中度  
- 浮盈浮亏与成本区  
- 风险预算剩余（VaR/回撤额度）  
- 持仓相关度（同涨同跌）  
- 生命周期：建仓 → 持有 → 加仓 → 减仓 → 清仓 → 冷静期

### 3.6 数据与工程往往比模型更决定成败

- Point-in-time 基本面、复权、停牌标记、财务口径一致性  
- 因子标准化、去极值、行业/市值中性化  
- 特征泄漏检测、训练/验证时间切分（Walk-forward）

### 3.7 用户体验上的关键缺口

- 置信度与「不知道」的表达（避免伪确定性）  
- 行为金融：追涨杀跌、处置效应、过度交易的干预  
- 教育层：让用户理解建议的假设与边界，而不是黑盒跟单

## 4. 对本产品的修正后能力地图（建议）

建议把能力拆成四层（后文产品文档会展开）：

1. **认知层**：行情/财报/宏观解读、术语与逻辑解释  
2. **分析层**：技术面、基本面、因子/模型信号、舆情  
3. **决策层**：在约束下生成买卖/加减仓/观望建议  
4. **风控层**：仓位、回撤、集中度、压力测试、合规提示  

「预测」只是分析层的一个子模块，不是产品全部。
