# 产品定位与边界

## 1. 建议定位（一句话）

**面向个人/小团队投资者的「场景化投研决策辅助系统」**：把行情、基本面、量化信号与风险约束，转成可解释的买卖/加减仓/观望建议，并持续监控失效与风险。

不是：保证收益的荐股；不是：未持牌代客理财；不是：无风控的全自动交易黑盒。

---

## 2. 目标用户分层

| 用户 | 需求 | 产品深度 |
|------|------|----------|
| 新手 | 看懂、少踩坑、规则提醒 | 教育 + 风控模板 + 简单信号 |
| 进阶个人 | 选股/择时辅助、仓位管理 | 多因子 + 场景建议 + 回测 |
| 量化爱好者 | 策略研究、因子实验 | 研究 Notebook + 回测引擎对接 |
| 小团队 | 统一投研流程与风控 | 组合优化 + 归因 + 合规日志 |

初期建议主攻：**进阶个人 + 可扩展到量化爱好者**。

---

## 3. 核心价值主张

1. **场景化**：同一信号，因持仓状态/市场状态/风险预算不同，建议不同  
2. **可解释**：每条建议可追溯到因子/指标/约束  
3. **概率化**：输出置信区间与失效条件，而不是「明天必涨」  
4. **风控优先**：先算「能亏多少」，再谈「可能赚多少」  
5. **可验证**：建议背后的规则/模型可回测、可样本外检验  

---

## 4. 功能边界（Must / Should / Won’t）

### Must（MVP）

- 标的与组合视图：持仓、成本、浮盈亏、集中度  
- 多维分析：量价技术、基础财务估值、简易因子分  
- 场景建议：建仓/加仓/减仓/清仓/观望 + 理由  
- 风险：波动、回撤、单票上限、简化 VaR  
- 回测沙盒：规则策略或因子策略的历史验证  
- 明确免责与「非投资顾问」声明  

### Should（V1）

- 多因子/轻量 ML 排序；行业与市值中性化  
- 组合优化（约束均值方差 / 风险平价简化版）  
- 舆情/研报摘要（LLM，需引用源）  
- Walk-forward、成本与涨跌停可成交性建模  
- 建议置信度与冲突提示（技术面 vs 基本面背离）  

### Won’t（早期明确不做）

- 承诺收益、跟单式「一键致富」  
- 高频/抢跑类程序化（监管与基建成本高）  
- 无券商资质的代客下单（除非合作持牌通道）  
- 把黑盒深度学习直接当最终交易指令  

---

## 5. 合规与表述边界

- 产品文案：辅助分析 / 研究工具 / 教育；避免「稳赚」「内幕」「荐股必中」  
- 若未来接智能投顾：需持牌机构合作与适当性管理  
- 程序化若自动下单：需关注报告义务、异常交易监控与券商前端管控  
- 模型输出必须带：**假设条件、数据截止时间、不确定性**  

---

## 6. 成功指标（产品，不是收益率玄学）

- 建议可解释覆盖率、用户采纳后的回撤改善（相对用户自身基准）  
- 回测与实盘偏差监控（滑点、成交率）  
- 用户过度交易次数下降、集中度违规率下降  
- 模型样本外 IC/IR 稳定性，而非单期暴利  

收益率可以展示，但**不应作为唯一 KPI**，否则产品会激励过拟合与营销话术。
