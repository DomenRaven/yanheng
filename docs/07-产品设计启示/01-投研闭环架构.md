# 投研闭环架构（目标产品骨架）

> 一句话：把先进量化流水线产品化——数据→特征→信号→组合→风控→建议→监控。

## 1. 逻辑架构

```text
┌──────────────┐
│ Data Layer   │ 行情/基本面/另类/用户账户
└──────┬───────┘
       ▼
┌──────────────┐
│ Feature/Factor│ 清洗、中性化、技术指标、文本特征
└──────┬───────┘
       ▼
┌──────────────┐
│ Signal Layer │ 规则 / 多因子 / ML / LLM 辅助解释
└──────┬───────┘
       ▼
┌──────────────┐
│ Portfolio Opt│ 约束优化、目标权重
└──────┬───────┘
       ▼
┌──────────────┐
│ Risk Engine  │ VaR/CVaR、限额、可交易性、合规
└──────┬───────┘
       ▼
┌──────────────┐
│ Advice Engine│ 场景状态机 → 建议卡片
└──────┬───────┘
       ▼
┌──────────────┐
│ Monitor      │ 衰减、漂移、回撤熔断、日志审计
└──────────────┘
```

## 2. 模块职责

| 模块 | 职责 | 非职责 |
|------|------|--------|
| Signal | 产生相对看法 | 不直接下满仓指令 |
| Portfolio | 变成权重 | 不解释用户情绪 |
| Risk | 否决/缩放 | 不发明 Alpha |
| Advice | 翻译成行动建议 | 不隐瞒不确定性 |
| Monitor | 看门 | 不事后改历史 |

## 3. 技术形态建议（后期实现）

- 后端：Python 投研服务 + 任务队列  
- 特征/模型注册表（版本化）  
- 建议 API：输入账户快照，输出建议列表  
- 前端：持仓驾驶舱 + 建议时间线 + 回测报告
