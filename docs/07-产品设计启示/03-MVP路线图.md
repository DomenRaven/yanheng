# MVP 路线图

> 一句话：先做「可解释的持仓顾问 + 稳健回测」，再叠加复杂预测模型。

## Phase 0 — 知识与口径（当前）

- 完成理论/工具库（本仓库）  
- 确定合规表述与产品边界  
- 选定初始市场：A 股中低频  

## Phase 1 — 分析驾驶舱（4–8 周量级，示意）

- 账户导入/手动持仓  
- 技术指标 + 基础财务估值面板  
- 集中度/波动/简化回撤风险  
- 规则型建议（无 ML）：超限减仓、趋势过滤等  
- 完整免责声明  

## Phase 2 — 因子与回测（8–16 周）

- 精简因子库（价值/质量/动量/流动性）  
- IC 报告与 Walk-forward  
- 向量化回测 + 成本/涨跌停  
- 建议引擎接入因子分与账户状态  

## Phase 3 — 组合优化与 ML（后续）

- 约束组合优化  
- LightGBM 排序模型  
- VaR/CVaR 限额  
- 监控与衰减下线  

## Phase 4 — 智能化与生态

- LLM 解释与研报摘要（带引用）  
- 可选券商/模拟盘对接  
- 持牌合作评估  

**工程状态（2026-09-16 对齐）**：研衡代码 Phase 4 已验收（LLM 解释层在列）。**模拟盘未做**（原 `phase0.5` 项 G），完整散户链按工程 **Phase 5** 实施，规格见 `stock-quant-system/docs/9.16-散户决策链需求规格.md`，产品补充见 `04-散户工作流与纸面账户.md`。

## 明确延后

- 高频、Level-2 博弈  
- 全自动实盘无人值守  
- 「保证收益」营销功能  

## 验收标准（Phase 1）

- 任意建议可追溯到规则  
- 风险超限时不能给出加仓建议  
- 用户能理解 T+1/涨跌停提示  
- 无违规收益承诺文案
