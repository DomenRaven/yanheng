# 散户工作流与纸面账户（产品规格补充）

> 一句话：把投研闭环的最后一公里写成「收盘出待办 → 次日执行或模拟 → 收盘再建议 → 周末复盘」，账户状态仍是一等公民，系统不下单。

## 2. 卡片字段补齐（相对 02 的 YAML）

02 已有：`action`、`size_pct_nav`、`horizon_days`、`confidence`、`reasons`、`invalid_if`、`constraints_applied`。

Phase 5 必须增加或生成：

- `size_shares`、`est_amount_cny`、`max_loss_cny`  
- `price_band` 或执行价口径（默认次日开盘）  
- `invalid_if` **可核验**条目（见 `../03-量化方法/15-日频信号与次日执行.md`）  
- `constraints_applied` 含 T+1、单票 15%、手数、现金缓冲  

`confidence` 继续用排名分位映射，UI 标明不是胜率。

`add`：Schema 保留；**禁止因浮亏触发**（`knowledge/indexes/scenarios.yaml` 的 `anti_patterns` 已写，引擎测试必须覆盖）。

## 3. 用户日频剧本

```text
T 日收盘后：数据更新 →（周末可选）重训 → scanner（只读冠军）
           → 明日待办 1–3 只 + 持仓卖/减股数
T+1：涨停/停牌 → 作废；否则模拟成交或券商手动下单后确认
T+1 收盘：持仓建议
周末：漂移 + 模拟周报（收益/回撤/换手/单票/run_id）
```

## 4. 合规与文案（所有新 UI）

- 辅助研究，不构成投资建议；模拟 ≠ 实盘。  
- 展示数据截止、`model_run_id`、费率、滑点、成交价口径。  
- 不承诺收益；不自动报单。
