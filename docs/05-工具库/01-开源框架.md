# 开源与平台工具框架

> 一句话：选型按阶段——研究扫描用向量化，路径依赖用事件驱动，AI 流水线用 Qlib，实盘对接用券商/平台 SDK。

## 1. 回测与研究

| 工具 | 定位 | 适合 |
|------|------|------|
| vectorbt | 高速向量化回测 | 参数扫描、因子研究 |
| backtrader | 事件驱动 | 复杂订单逻辑原型 |
| Zipline / Zipline-reloaded | 事件驱动（遗产多） | 学术/兼容旧代码 |
| QuantConnect LEAN | 研究+回测+实盘生态 | 多市场算法交易 |
| Microsoft Qlib | AI 量化全流程 | 因子/ML/组合流水线 |
| vn.py / 掘金等 | 国内实盘向 | 交易接口与策略运行 |

## 2. 数据与因子计算

| 工具 | 定位 |
|------|------|
| pandas / Polars / NumPy | 基础计算 |
| TA-Lib / pandas-ta | 技术指标 |
| alphalens-reloaded | 因子 IC/分层分析 |
| empyrical / quantstats / pyfolio-ish | 绩效分析 |
| cvxpy / Riskfolio-Lib | 组合优化 |
| statsmodels / arch | 时序与波动 |
| scikit-learn / LightGBM / PyTorch | ML/DL |

## 3. 国内投研平台（非开源但成熟）

| 平台 | 特点 |
|------|------|
| 聚宽 JoinQuant | 社区强、Python、入门友好 |
| 米筐 RiceQuant（RQData/RQAlpha/RQFactor/RQOptimizer） | 更机构化工具链 |
| 同花顺 SuperMind | 数据+回测+实盘衔接 |
| 优矿 / BigQuant 等 | 研究与可视化策略 |

## 4. 选型建议（本项目）

- **研究期**：Qlib 或自建 pandas + LightGBM + alphalens；快速扫描用 vectorbt  
- **策略逻辑复杂**：backtrader / LEAN 复核  
- **A 股数据**：先 AKShare/Tushare 验证概念，生产级再上商业数据（米筐/Wind/Choice 等）  
- **优化**：cvxpy 自研约束，或对接 RQOptimizer 思路
