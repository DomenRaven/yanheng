# 数据源

> 一句话：数据质量决定模型上限；区分「免费验证」与「生产可信」，并尽早引入 Point-in-time。

## 1. 数据类型地图

| 类型 | 内容 | 用途 |
|------|------|------|
| 行情 | OHLCV、复权、指数 | 技术/量价因子 |
| 基本面 | 财报、指标、一致预期 | 价值/质量/成长 |
| 微观结构 | Level-2、逐笔 | 高频/冲击成本（早期可不做） |
| 另类 | 舆情、新闻、卫星、招聘等 | 差异化 Alpha（成本高） |
| 宏观 | 利率、信用、政策 | 区制与配置 |
| 参考 | 行业分类、股本、日历 | 中性化与可交易性 |

## 2. 常见来源（中国个人/团队）

| 来源 | 特点 |
|------|------|
| AKShare | 开源免费，适合原型 |
| Tushare | 积分制，股票数据常用 |
| 聚宽 / 米筐数据 | 与回测环境一体 |
| 东方财富 / 同花顺生态 | 资讯与部分量化数据 |
| Wind / Choice | 机构级，贵但全 |
| 交易所 / 官方披露 | 权威但需工程化 |

国际：Yahoo/Polygon 等（若做美股）；Bloomberg/FactSet（机构）。

## 3. 质量检查清单

- [ ] 复权一致性  
- [ ] 停牌/涨跌停标记  
- [ ] 财务时点（公告日 vs 报告期）  
- [ ] 幸存者偏差  
- [ ] 时区与交易日历  
- [ ] 缺失与异常值处理策略固定  

## 4. 产品启示

- 抽象 `DataProvider` 接口，便于从免费切到商业  
- 所有特征打 `as_of` 时间戳  
- 对用户展示数据延迟与截止时间
