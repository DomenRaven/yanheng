# 数学模型与方法索引

按产品模块索引「成熟可用」的数学工具（非穷尽教科书）。

## 1. 收益与定价

| 模型 | 模块 | 成熟度 |
|------|------|--------|
| CAPM | 归因/期望收益 | 高 |
| Fama-French 3/5 | 归因/风格 | 高 |
| APT / 多因子线性 | 选股与风险 | 高 |
| Black-Litterman | 配置 | 中高 |
| DCF / DDM | 基本面绝对估值 | 高（假设敏感，见 `../12-估值与财务分析深度/01-绝对估值-DCF与DDM.md`） |
| 可比公司法（PE/PB/EV-EBITDA/PEG） | 基本面相对估值 | 高（依赖可比样本质量） |
| EVA / EPV | 护城河财务验证 | 中高 |
| Black-Scholes 期权定价 | 衍生品 | 高（`../10-衍生品与对冲工具/01-期权基础与希腊字母.md`） |
| 美林时钟 / 风险平价 / 全天候 | 大类资产配置 | 中高（美林时钟中国适用性有限，见 `../11-宏观与大类资产配置/`） |

## 2. 风险

| 模型 | 用途 | 成熟度 |
|------|------|--------|
| 样本协方差 / 收缩估计 | 组合风险 | 高 |
| 因子风险模型（Barra 类） | 风险预测/优化 | 高（工业） |
| EWMA / GARCH | 波动 | 高 |
| VaR / CVaR | 限额 | 高 |
| 压力测试 / 历史情景 | 尾部 | 高 |
| Copula | 相依结构 | 中（复杂） |

## 3. 优化与仓位

| 模型 | 用途 | 成熟度 |
|------|------|--------|
| 均值-方差 QP | 权重 | 高 |
| 风险平价 | 配置 | 高 |
| CVaR 优化 | 尾部 | 中高 |
| Kelly / 分数 Kelly | 仓位 | 高（需收缩） |
| 追踪误差约束 | 指数增强 | 高 |

## 4. 统计学习 / 深度学习

| 模型 | 用途 | 成熟度（金融落地） |
|------|------|-------------------|
| 线性/正则化回归 | 基线 | 很高 |
| GBDT | 表格选股 | 很高 |
| LSTM/TCN | 时序 | 中 |
| Transformer | 时序/多资产 | 中（研究热） |
| GNN | 关系建模 | 中 |
| HMM 区制 | 状态 | 中高 |
| 协整配对（Engle-Granger/Johansen） | 统计套利 | 中（约束多，见 `../03-量化方法/06-统计套利与配对交易.md`） |
| PCA 残差法 | 市场中性信号 | 中 |
| 事件研究法（CAR/AR） | 事件驱动 | 高（`../03-量化方法/07-事件驱动策略.md`） |
| TWAP/VWAP/POV/IS | 执行算法 | 高（`../03-量化方法/08-执行算法与做市.md`） |
| LLM 辅助 | 文本/因子假设/情绪NLP | 中（工程+合规，见 `../03-量化方法/09-另类数据与情绪NLP.md`） |

## 5. 评估统计

IC、RankIC、t 检验、Bootstrap、多重假设控制（如尝试 FDR）、Walk-forward、SPA/Deflated Sharpe 等进阶工具。
