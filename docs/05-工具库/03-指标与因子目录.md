## 1. 技术 / 量价类

| ID | 名称 | 逻辑摘要 |
|----|------|----------|
| TA-MA | 均线系统 | 趋势过滤 |
| TA-MACD | MACD | 动量与拐头 |
| TA-DMI | DMI/+DI/-DI/ADX | 趋势方向与强度 |
| TA-RSI | RSI | 超买超卖（≠ RS 相对强度） |
| TA-KDJ | KDJ | 短线摆动 |
| TA-WR | Williams %R | 超买超卖（与 KDJ 近亲） |

| TA-BIAS | 乖离率 | 价离均线程度 |
| TA-BB | 布林带 | 波动突破/回归 |
| TA-ATR | ATR | 波动与止损 |
| TA-VOL | 量价/换手/量比 | 真假突破与拥挤 |
| TA-OBV | OBV | 量价累积能量 |
| TA-VWAP | VWAP | 量价均价 |
| RS-REL | 相对强度 RS | 相对大盘/板块强弱 |

## 4. 入库标准（建议）

新因子必须提交：

1. 经济逻辑一页纸  
2. IC/分层/换手报告  
3. 与现有库相关矩阵  
4. 成本后净边缘  
5. 监控指标与下线阈值
