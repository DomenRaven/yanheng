# 筹码分布与持仓成本理论

> 一句话：筹码分布把「谁在什么价位持有多少仓位」可视化，用于估计套牢盘/获利盘压力，是量价分析与盘口博弈之间的桥梁。

## 1. 核心概念

| 概念 | 含义 |
|------|------|
| 筹码分布 | 各价位上估算的持仓数量分布（基于换手率模型推算，非精确账本） |
| 获利盘比例 | 当前价格以下的筹码占比（浮盈盘） |
| 套牢盘 | 当前价格以上的筹码（浮亏盘，构成上方压力） |
| 筹码集中度 | 分布是否集中在窄价格带（低集中度=分歧大，高集中度=主力控盘或长期盘整后单峰) |
| 成本重心迁移 | 主力成本区随时间上移/下移，反映吸筹或派发 |

## 2. 常见解读模式

| 形态 | 解读 |
|------|------|
| 单峰密集（低位） | 长期横盘后筹码高度集中，若放量突破，上方阻力小 |
| 单峰密集（高位）后放量下跌 | 可能是主力已经派发完毕，散户高位站岗 |
| 双峰/多峰分布 | 存在多个成本区，博弈激烈，突破需消化更多套牢盘 |
| 筹码持续下移 | 新增买盘成本降低，可能是缩量阴跌或换手 |
| 获利盘骤增 | 短期上涨后获利了结压力上升 |

## 3. 方法局限（必须明示）

- 筹码分布是**基于换手率的统计推算模型**，非真实持仓账本，存在模型误差  
- 对高换手、T+0式交易活跃股，估算偏差更大  
- 不能单独识别「主力」身份，只能反映价位结构  

## 4. 与其他理论的分工

| 问题 | 更合适工具 |
|------|------------|
| 上方压力大不大 | 筹码分布 |
| 现在有没有趋势 | 道氏/DMI |
| 短期该不该追 | 摆动指标 + 盘口 |
| 大资金意图 | 订单流（见 `../01-基础概念/07-市场盘口与交易微观结构.md`），需与筹码分布互相佐证而非替代 |

## 5. 产品启示

- 展示筹码分布时必须标注「模型估算，非真实持仓」  
- 结合获利盘比例设计止盈/止损提示（如获利盘 >90% 提示兑现压力）  
- 避免与「主力吸筹确定」类断言绑定，保持概率化表述
