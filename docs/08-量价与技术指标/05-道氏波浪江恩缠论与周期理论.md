# 经典技术理论体系：道氏理论 · 波浪理论 · 江恩理论 · 缠论 · 周期理论

> 一句话：这些是技术分析的「结构性大理论」，试图回答指标无法回答的问题——「现在处于什么级别的趋势、第几个阶段、大概到哪结束」；共同弱点是主观性强、可事后自洽、需严格规则化才能产品化。

## 1. 理论谱系定位

```text
技术分析
├── 指标类：MACD/KDJ/RSI/DMI...（局部、短期）
├── 形态类：K线组合、支撑阻力（中观结构）
└── 结构大理论：道氏/波浪/江恩/缠论/周期（宏观框架、流派化）
```

## 2. 道氏理论（Dow Theory）—— 技术分析鼻祖

### 六大原理

1. 价格反映一切已知信息  
2. 市场有三种趋势：主要趋势（年）、次要趋势（周月）、短暂趋势（日）  
3. 主要趋势分三阶段：积累期、公众参与期、派发期  
4. 指数间需相互验证（原始为铁路指数与工业指数）  
5. 成交量必须验证趋势  
6. 趋势持续有效，直到出现明确反转信号  

### 实战衍生：123 法则与 2B 法则

- 123 法则：趋势线跌破 + 无法创新高/新低 + 反向突破前高/前低，三步确认反转  
- 2B 法则：价格短暂突破前高/前低后迅速跌回，识别「假突破」的经典模型  

## 3. 波浪理论（Elliott Wave）

- 核心结构：**推动浪 5 浪（1-2-3-4-5）+ 调整浪 3 浪（A-B-C）** = 一个完整循环  
- 三条铁律：  
  1. 浪 2 不回撤超过浪 1 起点  
  2. 浪 3 不是三个驱动浪中最短的一浪  
  3. 浪 4 不进入浪 1 价格区间（不重叠）  
- 结合斐波那契比例（0.382/0.5/0.618/1.618）预测调整/延伸目标位  
- **最大风险**：数浪主观性极高，「事后都能数对，实时很难数对」；不应单独作为决策依据  

## 4. 江恩理论（Gann Theory）

- 融合时间、价格、几何角度（如 1x1 江恩角度线）  
- 核心信念：价格与时间存在自然周期共振  
- 争议大：可复现性与统计验证较弱，实务中更多作为辅助参考而非主决策工具  

## 5. 缠论（国内特色技术流派）

- 核心概念：笔、线段、中枢（价格震荡的中枢区间）、走势类型（趋势 vs 盘整）  
- 强调**中枢的构建与延伸/背驰**判断趋势力竭  
- 体系严谨但学习曲线陡峭，社区解读差异大，需谨慎标准化后再产品化  

## 6. 周期理论（Cycle Theory）

- 假设价格高低点在时间维度上存在规律性间隔  
- 可与季节性、日历效应等统计规律相互印证（见 `../03-量化方法/07-事件驱动策略.md` 中的日历效应）  

## 7. 综合使用与产品化原则

| 原则 | 说明 |
|------|------|
| 主观理论需规则化 | 产品中若引用波浪/缠论，必须转成可编程规则，禁止「感觉数浪」 |
| 多理论交叉验证 | 道氏定方向、指标找点、形态做确认，而非单一理论包打天下 |
| 禁止事后过度自洽 | 任何理论都能「事后看对」，回测与样本外检验是唯一试金石 |
| 免责表达 | 输出建议时应注明「基于结构性技术框架的概率判断」而非确定性预测 |
