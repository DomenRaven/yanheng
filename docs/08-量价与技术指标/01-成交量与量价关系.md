# 成交量与量价关系

> 一句话：价是结果，量是参与度；量价配合用于验证趋势与识别虚假突破，是技术分析的基础层。

## 1. 核心量

| 指标 | 含义 |
|------|------|
| 成交量 Volume | 成交股数/手数 |
| 成交额 Amount | 金额，跨股价更可比 |
| 换手率 | 活跃度与拥挤代理 |
| 量比 | 相对近期同期量能 |
| VWAP | 成交量加权均价（执行与盘感） |
| OBV | 能量潮：价涨加量、价跌减量累积 |

## 2. 经典量价关系（下属形态直觉）

| 组合 | 常见解读 | 失效注意 |
|------|----------|----------|
| 价涨量增 | 趋势健康 | 高潮末段也可能量增 |
| 价涨量缩 | 动能不足或惜售 | 强势股洗盘也可能缩量 |
| 价跌量增 | 抛压重 | 也可能是恐慌坑后转机 |
| 价跌量缩 | 下跌动能减弱或冷清 | 阴跌也可缩量长期跌 |
| 放量突破 | 有效性提高 | 对倒可造假量 |
| 放量滞涨 | 分歧/派发嫌疑 | 需结合位置 |

## 3. 平级类别

- 价格形态、摆动指标、趋势指标、盘口订单流、资金流向  

## 4. 产品启示

- 任何突破类建议默认要求「量能确认」开关  
- 题材高潮日的「天量」单独标记为风险事件
