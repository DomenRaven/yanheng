# 趋势与偏离类指标：DMI 及平级族

> 一句话：DMI/ADX 回答「有没有趋势、多空谁强」；与摆动类互补——有趋势才做突破，无趋势少做超买超卖逆势。

## 1. DMI（Directional Movement Index）

| 组件 | 含义 |
|------|------|
| +DI（PDI） | 上升方向力度 |
| −DI（MDI） | 下降方向力度 |
| ADX | 趋势强度（不区分方向） |
| ADXR | ADX 的平滑，确认用 |

### 常用解读

- +DI 上穿 −DI：多头占优信号（需 ADX 配合）  
- ADX 升破约 20–25：趋势市场；低于则偏盘整  
- ADX 高位拐头：趋势可能减速（不一定立刻反转）  
- 特点：相对滞后，更适中长线过滤  

## 2. 平级趋势族（应一并入库）

| 指标 | 角色 |
|------|------|
| MA / EMA / 均线多头排列 | 方向与支撑 |
| MACD | 趋势动量 |
| SAR 抛物线 | 趋势跟踪止损 |
| 趋势线 / 通道 | 结构 |
| ADX（可单用） | 强度过滤 |

## 3. 偏离类与 DMI 的分工

| 问题 | 优先指标 |
|------|----------|
| 有没有趋势？ | DMI/ADX、均线 |
| 是否极端远离均线？ | BIAS、CCI、布林 |
| 是否超买超卖？ | RSI/KDJ/WR |

## 4. 产品默认组合示例

`ADX 过滤` + `均线方向` + `RSI/BIAS 择时` + `成交量确认`  

避免：`KDJ+RSI+WR+CCI` 四重摆动堆叠。
