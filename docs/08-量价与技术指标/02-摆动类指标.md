# 摆动类指标：KDJ · RSI · WR · CCI · BIAS

> 一句话：摆动指标描述价格在近期区间中的相对位置与动量极端程度；适合辅助择时，震荡市假信号多，须与趋势过滤和量能合用。

## 1. 指标族定位

```text
技术指标
├── 趋势类：MA/MACD/DMI(ADX)...
├── 摆动/超买超卖类：KDJ/RSI/WR/CCI...
├── 偏离类：BIAS/布林%B（与CCI交叉）
└── 量价类：Volume/OBV...
```

## 2. 名词与要点

### KDJ（随机指标 Stochastic 的常用变体）

- 成分：K、D、J  
- 直觉：收盘价在近期最高最低区间中的位置  
- 用法：金叉死叉、超买超卖区、背离  
- 特点：灵敏，假信号多，偏短线  

A 股软件里的「KDJ 普通版」不是 TA-Lib 的 `STOCH`（后者对 %K/%D 做简单移动平均）。通达信公式系统给出的形式是：

```text
RSV:=(CLOSE-LLV(LOW,N))/(HHV(HIGH,N)-LLV(LOW,N))*100;
K:SMA(RSV,M1,1);
D:SMA(K,M2,1);
J:3*K-2*D;
```

其中 `SMA(X,N,M)` 的权重递推为 `Y=(X*M+Y'*(N-M))/N`（见通达信官方算法说明）。公式编辑器缺省参数是 `N=9, M1=3, M2=3`，即 `K` 的更新为 `(RSV+2*K')/3`。`J=3K-2D` 是国内软件把快慢线距离放大的扩展，不是 George Lane 原始随机指标的定义。最高价等于最低价时 RSV 无定义，不应填一个假的 50 再拿去交易。参数敏感，验证策略时固定缺省参数，不要事后搜索「最佳周期」。

### RSI（Relative Strength Index）

- 直觉：一段时间内上涨幅度 vs 下跌幅度  
- 常见阈值：70/30 或 80/20  
- **重要辨析**：RSI ≠ **RS 相对强度**（个股相对大盘/板块的强弱）  
- 用法：超买超卖、中轴 50、背离  

### WR（Williams %R）

- 直觉：与随机指标同类，刻度常为 −100～0 或 0～100（软件不同）  
- 用法：极端区回归；与 KDJ 高度相关，勿重复加权  

### CCI（Commodity Channel Index，顺势指标）

- 直觉：价格相对均价的偏离（按均绝对偏差标准化）  
- 关键：±100 区域、0 轴、背离  
- 特点：可突破常规界限，偏「异常波动」捕捉  

### BIAS（乖离率）

- 直觉：(价 − 均线) / 均线  
- 用法：正乖离过大防回撤，负乖离过大看反弹（阈值因品种波动而异）  
- 与布林带、CCI 同属「偏离」思想  

## 3. 合用原则（产品规则建议）

1. 先用趋势类（均线/DMI）定方向，再用摆动类找点  
2. 多指标同族高度相关 → **只选 1～2 个**，避免伪共振  
3. 必须叠加：级别（日/周）、量能、位置（支撑阻力）  
4. 参数敏感 → 默认参数 + 稳健性说明，禁止神话「最佳参数」
