# K线形态学

> 一句话：K线记录一段时间内多空博弈的结果；单根/组合形态能提示情绪极端与短期转折概率，但必须结合位置（趋势中/末端）与量能，孤立形态可信度低。

## 1. 单根K线关键信息

| 要素 | 含义 |
|------|------|
| 实体（开盘-收盘） | 多空最终力量对比 |
| 上影线 | 盘中上冲遇阻回落，卖压证据 |
| 下影线 | 盘中下探获支撑回升，买盘证据 |
| 长/短实体 | 力量悬殊程度 |

## 2. 单根形态（下属清单）

| 形态 | 位置含义 |
|------|----------|
| 十字星 | 多空分歧加大，趋势末端警示 |
| 锤子线 | 下跌趋势末端，长下影，潜在见底 |
| 上吊线 | 上涨趋势末端，形态同锤子线但含义相反 |
| 倒锤子/射击之星 | 上涨末端受阻信号（射击之星更偏顶部） |
| 光头光脚阳/阴线 | 单边力量极强，趋势延续概率较高 |

## 3. 组合形态

| 形态 | 说明 |
|------|------|
| 吞没形态（看涨/看跌） | 第二根实体完全吞没第一根，力量反转信号 |
| 乌云盖顶 / 曙光初现 | 顶部/底部反转组合 |
| 早晨之星 / 黄昏之星 | 三根K线构成的经典底/顶反转 |
| островный反转（岛形反转） | 跳空缺口孤立价格区域后反向跳空 |

## 4. 缺口理论

| 缺口类型 | 含义 |
|----------|------|
| 突破缺口 | 出现在形态突破处，量能配合则可信度高 |
| 持续缺口（中继缺口） | 趋势中段，衡量剩余空间的参考 |
| 竭尽缺口 | 趋势末端加速后的缺口，随后易回补 |
| 岛形反转缺口 | 竭尽缺口 + 反向突破缺口，强烈反转信号 |

## 5. 使用纪律（避免「看图说故事」）

1. 形态必须结合**位置**：底部锤子线 ≠ 上涨途中的锤子线  
2. 必须有**成交量确认**：无量的反转形态可信度低  
3. 单一形态不作为独立决策依据，需与趋势指标（DMI/均线）共振  
4. 形态识别存在主观性，产品化时应给出规则化、参数化定义，避免「事后诸葛」
