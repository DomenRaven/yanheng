# 利率、流动性与信用周期

> 一句话：比「经济好不好」更直接驱动短期资产价格的，常常是「钱多不多、贵不贵」——利率与流动性周期是美林时钟之外更贴近实盘的分析维度。

## 1. 核心变量

| 变量 | 含义 | 对股市影响直觉 |
|------|------|----------------|
| 政策利率 | 央行基准利率/公开市场操作利率 | 降息通常利好估值（折现率下降） |
| 市场利率 | 银行间利率、国债收益率 | 利率快速上行常压制高估值成长股 |
| M1/M2 增速 | 货币供应量 | M1 走强常与企业活期存款增加、经济活跃度相关 |
| 社融/信贷 | 信用派生速度 | 信用扩张周期通常伴随权益市场风险偏好回升 |
| 十年期国债收益率 | 无风险利率代理 | 股权风险溢价（ERP）= 股票预期收益 − 无风险利率 |

## 2. 利率对股票估值的传导

- DCF 视角：无风险利率上升 → WACC/折现率上升 → 同等盈利下估值下降，成长股（现金流更靠后）受冲击更大  
- 利率下行周期：长久期资产（高成长、高PE）相对受益  
- 利率快速上行阶段：全类资产承压，「现金为王」（见美林时钟利率轴改良）  

## 3. 信用周期与市场风险偏好

- 信用扩张（社融回升）：企业融资环境改善，往往伴随周期股、中小盘风险偏好回升  
- 信用收缩：违约风险上升，市场更偏好确定性强的龙头与防御板块  

## 4. 股权风险溢价（ERP）框架

\[
ERP = \frac{1}{PE_{\text{指数}}} - r_{\text{十年期国债}}
\]

- ERP 处于历史高位：权益相对债券的性价比较高（不代表立即上涨，是中长期配置参考）  
- ERP 处于历史低位：权益吸引力下降，需更谨慎  

## 5. 产品启示

- 宏观仪表盘应展示：政策利率趋势、十年期国债收益率、M1-M2 剪刀差、社融增速  
- ERP 分位数可作为「当前市场整体贵不贵」的辅助展示指标（非择时信号）  
- 与美林时钟联立使用：先看利率驱动的资产偏好，再叠加增长通胀象限做精细化判断
