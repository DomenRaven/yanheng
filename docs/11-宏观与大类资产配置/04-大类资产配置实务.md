# 大类资产配置实务

> 一句话：大类资产配置决定组合长期收益的绝大部分方差来源；个股择时的边际贡献远小于「股债商现金怎么分」这个顶层决策。

## 1. 主要资产类别

| 类别 | 代表 | 核心风险 |
|------|------|----------|
| 权益 | A股/港股/美股/宽基或行业ETF | 市场系统性风险、估值波动 |
| 固定收益 | 国债、信用债、货币基金 | 利率风险、信用风险 |
| 商品 | 黄金、原油、工业金属 | 供需与地缘政治冲击 |
| 现金及等价物 | 货币基金、短期存款 | 机会成本、通胀侵蚀 |
| 另类资产 | REITs、私募股权（个人参与度有限） | 流动性风险 |

## 2. 经典配置策略谱系

| 策略 | 逻辑 |
|------|------|
| 战略资产配置 SAA | 长期目标权重，基于风险承受能力与目标 |
| 战术资产配置 TAA | 短中期根据市场判断偏离 SAA，寻求超额 |
| 美林时钟轮动 | 按周期阶段切换占优资产（见 `01`） |
| 风险平价/全天候 | 按风险贡献而非资金权重配置（见 `03`） |
| 生命周期/目标日期策略 | 随年龄/目标日期临近降低权益比例 |
| 核心-卫星策略 | 核心仓位配置宽基/低成本工具，卫星仓位博取超额 |

## 3. 个人投资者简化框架（产品可落地）

```text
1. 明确目标：期限、流动性需求、风险承受能力
2. 设定股债现金基准比例（如 60/30/10，按风险偏好调整）
3. 核心仓位：宽基ETF/低费率工具，长期持有
4. 卫星仓位：行业/主题/个股，控制总仓位上限
5. 再平衡：定期或阈值触发（见 ../04-风险管理/06-调仓与再平衡.md）
6. 宏观复核：结合利率/流动性周期微调股债比例，而非频繁择时
```

## 4. 常见误区

- 只做「选股」不做「配置」：忽视顶层资产比例对长期结果的主导作用  
- 把全部资金押注单一宏观叙事（如「全仓押通胀」）  
- 频繁根据短期宏观新闻大幅调整配置，换手成本吃掉长期收益  

## 5. 产品启示

- 账户驾驶舱应展示「大类资产敞口」视图，而不仅是个股列表  
- 组合建议应先做资产配置健康检查，再进入个股/行业层面建议
