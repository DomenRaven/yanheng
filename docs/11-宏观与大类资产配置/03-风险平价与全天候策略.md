# 风险平价与全天候策略

> 一句话：与其猜测经济处于哪个周期象限，不如让组合对「增长意外」和「通胀意外」都有对冲——全天候策略用风险平价代替对宏观方向的主观押注。

## 1. 风险平价（Risk Parity）核心思想

- 传统 60/40（股/债）组合中，股票贡献了绝大部分风险（尽管资金权重不高）  
- 风险平价：按**风险贡献**而非**资金权重**分配，使每类资产对组合总风险的贡献相等  
- 通常需要对低波动资产（如债券）加杠杆，才能在风险平配后仍获得可观收益  

\[
\text{风险贡献}_i = w_i \times \frac{\partial \sigma_p}{\partial w_i} \quad \text{目标：各资产风险贡献相等}
\]

## 2. 全天候策略（All Weather，桥水）

- 不预测「处于哪个经济阶段」，而是按**增长/通胀是否超预期**划分四象限，为每个象限配置能在该情形下表现良好的资产  

| 象限 | 表现较好的资产类型 |
|------|--------------------|
| 增长超预期 | 股票、大宗商品、信用债 |
| 增长不及预期 | 名义债券、抗通缩资产 |
| 通胀超预期 | 抗通胀债券（如挂钩通胀债券）、商品 |
| 通胀不及预期 | 名义债券、股票（温和环境） |

- 核心工具依然是风险平价：确保组合不会因单一宏观情形（如通胀骤升）而遭受集中损失  

## 3. 局限与注意事项

- 依赖**低相关性假设**：危机时期资产相关性普遍上升，风险平价的分散效果会减弱  
- 常需杠杆放大低波动资产收益，杠杆本身在流动性危机中是风险来源  
- 对个人投资者：完整全天候策略涉及国债、通胀挂钩债、商品期货等工具，落地门槛高；更实际的是**借鉴其风险均衡理念**而非照搬满血版实现  

## 4. 对权益个人投资者的简化启示

- 用**波动率倒数加权**替代等资金权重配置行业/主题（简化版风险平价）  
- 避免把仓位集中在单一宏观暴露（如全仓强周期股 = 只赌「增长超预期」象限）  
- 组合应问自己：「如果通胀超预期/增长不及预期，我的持仓会怎样？」  

## 5. 产品启示

- 组合诊断功能可加入「宏观情形敏感性」标签：当前持仓更像哪个象限的赌注  
- 高级用户可提供简化风险平价再平衡建议（结合 `../03-量化方法/04-组合优化.md`）
