# 美林时钟与经济周期

> 一句话：美林时钟用「增长×通胀」两个维度把经济周期分成四象限，指导大类资产轮动；在中国市场需谨慎——常出现「跳档」或与政策周期错位，不能死板套用。

## 1. 经典四象限

| 阶段 | 特征（GDP/CPI） | 最优资产 | 次优资产 |
|------|------------------|----------|----------|
| 复苏 | 高增长、低通胀 | 股票 | 债券 |
| 过热 | 高增长、高通胀 | 商品 | 股票（结构性） |
| 滞胀 | 低增长、高通胀 | 现金 | 商品 |
| 衰退 | 低增长、低通胀 | 债券 | 现金 |

顺时针循环：衰退 → 复苏 → 过热 → 滞胀 → （回到衰退）。

## 2. 行业板块与周期的对应（A股参考）

| 阶段 | 占优板块逻辑 |
|------|--------------|
| 衰退 | 金融、必需消费（防御，受益于宽货币） |
| 复苏 | 周期、金融（盈利改善 + 流动性宽松双击） |
| 过热 | 周期、可选消费（景气仍在但流动性开始收紧） |
| 滞胀 | 必需消费、部分资源品（抗通胀属性） |

## 3. 中国市场的失效与改良

- 中国宏观调控目标多元（增长、就业、金融稳定、内外平衡），与美国以通胀/增长为核心的政策框架不完全对应，直接套用准确率有限  
- 改良思路：**以利率为轴扩展四象限**  
  - 利率强上行：流动性紧张，「现金为王」几乎适用于所有周期阶段（股债商三杀风险）  
  - 利率强下行：流动性充裕叠加加杠杆，可能使股票在「过热」阶段跑赢商品（偏离经典模型）  
- 实证：直接套用经典美林时钟的中国市场准确率明显低于以利率为轴改良后的模型（研究报告口径差异较大，仅作方向参考，非精确数字承诺）  

## 4. 产品启示

- 宏观模块应输出「增长×通胀×流动性」三维坐标，而非机械的四象限贴标签  
- 明确提示：美林时钟是**方向性框架**，不是精确择时工具，需结合利率与政策信号  
- 主题/行业建议应能关联当前推断的周期阶段，作为「产业面」判断的宏观背景（见 `../01-基础概念/05-产业面与行业分析.md`）
