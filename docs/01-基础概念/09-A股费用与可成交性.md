# A股费用与可成交性（执行层）

> 一句话：一张模拟单能成交，当且仅当：不是停牌、未封死涨跌停、股数合法、T+1 允许卖、扣费后现金不为负；费用按法定项目 + 券商佣金模板计算，不凭印象。

## 1. 与已有制度文档的分工

| 文档 | 管什么 |
|------|--------|
| `02-A股市场制度.md` | T+1、涨跌停、停牌、程序化监管、荐股表述 |
| `08-A股交易制度深化.md` | 注册制、退市、板块涨跌幅、两融 |
| **本文** | **算费与可成交判定**，供纸面经纪与回测共用 |

数字具有时效性；产品参数必须可配置。以下为 **2026-09 复核的常用口径**，上线前对照交易所/中国结算/财政部当期公告。

## 2. 费用三项

| 项目 | 收取 | 常用口径 | 权威/核验 |
|------|------|----------|-----------|
| 印花税 | 卖出单边 | 成交额 **0.05%**（2023-08-28 减半）；北交所股票常暂免 | 财政部印花税法及减半通知；与 `08` 第三轮核验一致 |
| 过户费 | 买卖双向 | 成交额 **0.001%**（十万分之一）量级 | 券商公示、中国结算业务收费；以 `chinaclear.cn` 当期表为准 |
| 佣金 | 买卖双向 | 监管上限成交额 **0.3%**；市场常见万一～万三；**单笔不足 5 元按 5 元** | 券商公示（如国新、长江等公开收费表） |

实现必须复用 `stock-quant-system/research/a_share_rules.py` 的 `CostAssumptions` / `apply_costs`（默认佣金万三、最低 5 元、印花税 0.05%、过户费 0.001%），**禁止**在 `paper_broker` 里另写一套税率。

**小资金含义**：1 万账户买卖 1 手低价股时，5 元最低佣金会把有效费率抬到远高于名义万三。这是小账户损耗的制度来源之一，不是「设置太严」。Jones 等工作论文用 BLLO 跟踪组合估计：相对持仓，RT2（10–50 万）费用项最重（约 −1.80% 年化），RT1 约 −1.38%——活跃中户付费最多；1 万账户还会额外撞上 5 元下限，两边都要进模拟盘。

## 3. 可成交判定顺序（建议）

1. 标的当日是否在交易日历内、是否停牌。  
2. 买入：是否涨停封死；卖出：是否跌停封死。阈值函数已在 `limit_pct` / `is_limit_locked`。  
3. 买入股数必须为 100 的整数倍且 ≥100；卖出股数 ≤ T+1 可卖（当日买入不可卖）。  
4. 买入：现金 ≥ 价款 + 费用；卖出后现金与持仓一致。  
5. 失败原因写入成交拒绝日志，供 UI 显示（涨停 / 停牌 / 手数 / T+1 / 现金不足）。

滑点：回测与模拟可用固定 bp 或开盘价偏移；**必须标注非真实盘口**。个人 1 万冲击通常小于费用与涨停不可买，不要用机构 TWAP 故事吓唬用户，也不要假装滑点为零。

## 4. 产品启示

- `config.yaml` 的 `paper_trading` 只覆盖「可谈的佣金/滑点」，法定印花税/过户费默认跟上 `CostAssumptions`，改法定税率时改一处。  
- 费用展示在待办卡片上（预估），成交后再写 `paper_trades.fees`。  
- 北交所印花税暂免已在 `apply_costs(exchange=="bj")`；模拟盘勿漏。
