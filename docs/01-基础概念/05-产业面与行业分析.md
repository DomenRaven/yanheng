# 产业面与行业分析

> 一句话：产业面是中观基本面——回答「这个行业现在处于景气周期的哪一段、竞争与政策是否支持盈利兑现」。

## 1. 在分析体系中的位置

| 层级 | 名称 | 问题 |
|------|------|------|
| 宏观 | 经济/利率/流动性 | 大环境 |
| **中观·产业面** | 行业与产业链 | 景气与格局 |
| 微观·公司 | 财务与治理 | 谁能兑现 |
| 主题·概念 | 叙事与注意力 | 短期定价扰动 |

产业面 ≠ 概念面：前者重**盈利与产能逻辑**，后者重**叙事与资金博弈**。

## 2. 下属核心概念

| 概念 | 说明 |
|------|------|
| 产业链上下游 | 原材料→制造→应用；利润在哪一环 |
| 行业景气度 | 开工率、库存、价格、订单、产能利用率 |
| 竞争格局 | 集中度、护城河、价格战风险 |
| 渗透率 / 天花板 | 成长阶段（导入/成长/成熟/衰退） |
| 政策与监管 | 补贴、准入、安全、出口管制 |
| 技术路线更替 | 如新旧能源、新旧工艺替代风险 |
| 周期属性 | 成长股 vs 周期股的分析框架不同 |
| 比较估值 | 行业 PE/PB 分位、相对历史与全球同业 |

## 3. 平级类别（分析维度族）

- 宏观面、产业面、公司基本面、技术面、资金/盘口面、情绪/主题面、量化因子面  

## 4. 常用分析步骤（产品可模板化）

1. 定义行业边界与可比公司池  
2. 判断景气方向（改善/恶化/拐点）  
3. 判断谁受益（龙头 vs 弹性小票）  
4. 估值是否已透支景气  
5. 与主题热度分离：热度高但景气未兑现 → 交易属性上升  

## 5. 产品启示

- 产业面输出：「景气方向 + 受益环节 + 估值拥挤」三件套  
- 机器人、商业航天等：区分**科研成果**与**上市公司收入兑现时滞**
