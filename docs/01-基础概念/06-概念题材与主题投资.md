# 概念题材与主题投资

> 一句话：概念/题材是注意力驱动的定价力量；可交易，但极易拥挤与退潮，必须用生命周期与兑现度管理。

## 1. 名词辨析

| 词 | 含义 |
|----|------|
| 概念 / 题材 | A股语境下围绕叙事的股票篮子（AI、机器人、商业航天等） |
| 主题投资 | 机构化说法：按长期趋势配置主题暴露 |
| 事件驱动 | 公告、政策、技术突破、并购等催化 |
| 纯概念炒作 | 叙事强、基本面弱或远、换手极高 |

## 2. 主题生命周期（下属阶段）

1. **萌芽**：少数人定价，波动不一定大  
2. **扩散**：媒体/社群扩散，龙头率先涨  
3. **高潮**：高标股、跟风股齐涨，估值极端，拥挤  
4. **分歧/退潮**：利好兑现卖出，分化加剧  
5. **沉寂或基本面承接**：留下有业绩的，淘汰纯叙事  

## 3. 平级与相关概念

- 产业面（兑现）、资金面（抱团）、情绪面（FOMO）、政策面  
- 注意力资产定价、叙事经济学、拥挤度、动量拥挤反转  
- 事件研究（Event Study）：催化前后的异常收益  

## 4. 判断「火热能不能买」的检查清单

| 检查项 | 偏买入逻辑 | 偏卖出/观望逻辑 |
|--------|------------|-----------------|
| 催化真实性 | 可验证进展、可追踪订单 | 仅标题党/传闻 |
| 与上市公司关联 | 收入/订单明确 | 「沾边」映射 |
| 估值与涨幅 | 仍处扩散早期 | 高潮且涨幅巨大 |
| 拥挤度 | 换手与持仓未极端 | 全民热议、龙虎榜高度一致 |
| 产业兑现时滞 | 有清晰里程碑 | 商业化遥远 |
| 相对强弱 | 龙头持续强于板块 | 高标股见顶、跟风补涨 |

**常见误区**：把「科研成果」直接等同「相关股票应立刻买入」——股价往往已部分或过度反应。

## 5. 产品启示

- 主题卡片强制字段：生命周期阶段、拥挤度、兑现线索、映射纯度  
- 高潮阶段默认建议「减仓/兑现」权重上升，而非继续追高模板
