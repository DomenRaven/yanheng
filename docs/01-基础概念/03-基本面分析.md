# 基本面分析

> 一句话：基本面回答「这家公司值多少、质地如何」；适合中长线与选股过滤，不单独解决精确择时。

## 1. 分析框架（三层）

1. **宏观 / 行业**：景气、政策、竞争格局  
2. **公司质量**：盈利能力、成长、现金流、杠杆、治理  
3. **估值**：贵不贵（相对历史、相对同行、绝对估值）  

## 2. 常用财务与估值指标

| 指标 | 含义 | 使用注意 |
|------|------|----------|
| ROE | 股东权益回报率 | 看水平、稳定性与杜邦拆解；高 ROE 可能伴随高杠杆 |
| 毛利率 / 净利率 | 产品与整体盈利能力 | 行业不可比；关注趋势 |
| 营收/利润增速 | 成长性 | 区分一次性与可持续 |
| 经营现金流 | 利润含金量 | 长期现金流差需警惕 |
| 资产负债率 / 利息保障 | 偿债压力 | 周期行业高杠杆危险 |
| PE | 市盈率 | 适合盈利稳定公司；周期股看谷峰 |
| PB | 市净率 | 金融、重资产更常用 |
| PS / EV-EBITDA | 收入与企业价值倍数 | 未盈利或重资本开支场景 |
| PEG | PE / 增长 | 粗筛成长股，增长预测误差大 |
| 股息率 | 分红回报 | 看可持续分红能力 |

## 3. 估值方法概览

- **相对估值**：与历史分位、同行比较  
- **绝对估值**：DCF（自由现金流折现）、股利折现等  
- **质量+估值**：高质量公司可承受更高倍数，但需成长兑现  

## 4. 数据坑（产品必须处理）

- 财报发布滞后与**修订**  
- **Point-in-time**：回测只能用当时可知的数据，禁止偷看未来财报  
- 口径差异：TTM、单季、累计；非经常性损益  
- 商誉减值、会计政策变更造成的「假恶化/假改善」  

## 5. 产品启示

- 基本面模块输出：「质量分 + 估值分 + 风险旗标」优于单一 PE  
- 与技术面冲突时，明确展示**冲突**而非强行合成一个分数  
- 适合作为选股池过滤器与中长线建议依据
