# A股市场制度（产品必须内建的约束）

> 一句话：A 股不是美股的缩小版；T+1、涨跌停、停牌与程序化监管会直接改变策略可执行性与产品合规边界。

## 1. 交易基础规则

| 规则 | 含义 | 对策略/产品的影响 |
|------|------|-------------------|
| T+1 | 当日买入，下一交易日才可卖出 | 禁止真正的日频「买了马上卖」；短线风险放大 |
| 涨跌停 | 多数股票日涨跌幅限制（主板约±10%，创业板/科创板等另有规定，以现行规则为准） | 信号可能无法成交；排队与封单行为重要 |
| 停牌 | 重大事项可停牌 | 回测必须处理不可交易；持仓可能被动锁死 |
| 集合竞价 / 连续竞价 | 开收盘与盘中撮合机制不同 | 开盘跳空、尾盘效应需建模 |
| ST/*ST 等风险警示 | 财务或规范问题公司 | 默认过滤或强提示 |

## 2. 成本与微观结构

- 佣金（双向、券商协商费率）、印花税（现行税率0.05%即万分之五，仅卖出单边征收，2023-08-28起减半执行，北交所股票暂免征）、过户费等构成显性成本  
- 滑点与冲击成本：资金越大、流动性越差，越不可忽略  
- 回测若用「收盘价无摩擦成交」，实盘会系统性地变差  

## 3. 程序化交易监管要点（2024–2025 起强化）

依据证监会《证券市场程序化交易管理规定（试行）》及沪深北交易所实施细则（约 2025-07 起施行相关细则）：

- **程序化交易**：计算机程序自动生成或下达交易指令（含量化选股择时与算法拆单）  
- **报告义务**：相关投资者需按规定报告；券商前端管控  
- **重点监控异常行为**（细则细化）：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交等  
- **高频认定（细则口径）**：常见表述为单账户每秒申报撤单合计达一定笔数，或全日达到较高笔数阈值（产品设计勿鼓励触碰红线）  

**产品启示**：个人辅助工具应默认「中低频、可解释、人工确认」；若未来自动下单，必须预留合规报备与风控日志。

## 4. 智能投顾 / 荐股表述

- 持牌智能投顾 ≠ 民间「AI 荐股」  
- 未持牌产品应避免：代客决策、收益承诺、隐瞒逻辑的「玄学系统」  
- 建议输出格式：分析结论 + 用户自行决策 + 风险提示  

## 5. 产品内建检查清单

- [ ] 建议是否考虑 T+1（今日买明日才能卖）  
- [ ] 是否提示涨跌停/停牌导致无法执行  
- [ ] 回测是否含成本与成交约束  
- [ ] 文案是否避免承诺收益  
- [ ] 若自动化：是否有异常交易自检与速率限制
