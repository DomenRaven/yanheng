# A股交易制度深化：注册制 · 退市 · 北交所 · 打新

> 一句话：制度是"游戏规则的边界"——不理解注册制下的退市红线和打新博弈，很容易把"制度性风险"误判为"基本面机会"。

## 1. 全面注册制要点（对交易与融资融券的影响）

- 上市审核由核准制转向以信息披露为核心的注册制，发行定价市场化（取消发行市盈率限制）  
- 允许未盈利企业（如科创板部分企业）、红筹企业上市 → 需要更依赖现金流/成长性分析而非单纯PE筛选  
- 注册制下新股上市首日即可纳入融资融券标的，转融通标的同步扩容，双向价格发现效率提升，但也意味着新股上市初期波动可能因两融资金介入而放大  

## 2. 退市制度深化

| 退市类型 | 触发条件（2024年4月沪深北三所修订、2026年年报季全面实施的口径） |
|----------|--------------------------------------|
| 财务类退市（"组合退"） | 最近一个会计年度经审计的利润总额、净利润、扣除非经常性损益后净利润三者孰低为负值，且扣除后营业收入低于：**主板3亿元、创业板/科创板1亿元、北交所5000万元**（主板此前为1亿元，2024年修订上调至3亿元） |
| 净资产类退市 | 最近一个会计年度经审计期末净资产为负值 |
| 审计意见类退市 | 最近一个会计年度财务会计报告被出具无法表示意见或否定意见 |
| 交易类退市 | 股价连续低于面值（面值退市）、成交量/市值持续低迷 |
| 规范类退市 | 信息披露违规、财务造假等重大违规 |
| 重大违法类退市 | 欺诈发行、重大信息披露违法 |

**产品启示**：财务红旗清单（见 `../12-估值与财务分析深度/05-财务造假识别与红旗清单.md`）与退市指标应联动，对"披星戴帽"（ST/*ST）或触及退市预警的标的强制风险提示。

## 3. 北交所

- 定位服务创新型中小企业，是多层次资本市场体系的重要一层（与主板、科创板、创业板并列）  
- 已发布融资融券交易细则，总体比照沪深两融成熟模式构建（券源、投资者适当性管理等仍在完善中）  
- 流动性通常低于沪深主板，换手率与冲击成本需重点关注（呼应流动性风险章节）  

## 4. 打新与配债

| 类型 | 逻辑 |
|------|------|
| 新股打新 | 网上/网下申购中签后按发行价获配，上市后博弈溢价（需评估破发风险，注册制下已非稳赚） |
| 可转债打新 | 优先配售 + 网上申购，中签后上市首日择机卖出（历史上溢价率相对新股更稳定，但也存在破发案例） |
| 战略配售 | 大型企业上市的机构/员工优先配售机制 |

**风险提示**：注册制下新股定价市场化，"打新稳赚"的历史经验已不再普适，破发案例增多，需结合发行估值与行业热度评估。

## 5. 涨跌幅与风险警示分层（制度速览，衔接已有A股制度文档）

| 板块/状态 | 涨跌幅限制（2026-07-06新规实施后） |
|-----------|--------------------------------------|
| 主板普通股票 | 10% |
| 主板 ST/\*ST 股票 | 10%（**2026-07-06起**由此前的5%上调至与主板普通股一致，产品/回测中若沿用旧版5%需及时修正） |
| 科创板/创业板（含风险警示股票） | 20% |
| 北交所（含风险警示股票） | 30% |
| 新股上市前5个交易日 | 不设涨跌幅限制（各板块一致），设30%/60%两档临时停牌机制 |

**核验提醒**：本表已按 2026-08 复核更新；A股交易制度变动频率较高（如本次ST涨跌幅调整间隔仅3个月的过渡期即落地），产品应将涨跌幅参数做成可配置项而非硬编码，并建立制度变更监控流程。

## 6. 产品启示

- 股票详情页应展示制度标签：板块类型、涨跌幅限制、是否ST、是否两融标的  
- 打新/配债功能需展示破发概率的历史统计参考，而非暗示无风险收益  
- 退市风险预警应作为独立的强提示模块，优先级高于常规技术面信号
