# 技术分析

> 一句话：技术分析用价格与成交量的历史形态估计供需与动量；擅长描述「现在处于什么状态」，对长期基本面解释力弱。

## 1. 前提与边界

- 假设：价格反映信息；部分模式会重复；趋势有持续性或均值回归  
- 局限：指标滞后、参数敏感、震荡市假信号多；单独使用易过度交易  
- 与量化关系：大量技术指标可被当作**特征/因子**，但需严格统计检验  

## 2. 常用指标（成熟工具）

| 指标 | 类型 | 直觉 |
|------|------|------|
| MA / EMA | 趋势 | 平滑价格，多空排列 |
| MACD | 趋势+动量 | DIF/DEA/柱：趋势强度与拐头 |
| RSI | 摆动 | 超买超卖与动能（≠ RS 相对强度） |
| KDJ | 摆动 | 短线敏感，假信号也多 |
| WR | 摆动 | 与随机指标近亲 |
| CCI | 偏离/摆动 | ±100 与异常波动 |
| BIAS | 偏离 | 价离均线乖离 |
| DMI/ADX | 趋势 | 多空方向与趋势强度 |
| 布林带 | 波动 | 波动扩张/收敛与突破 |
| ATR | 波动 | 用于止损距离与仓位 |
| OBV / 成交量 | 量价 | 价涨量增更可信 |
| 支撑阻力 / 形态 | 结构 | 主观性强，适合辅助非唯一依据 |

详解专章：`../08-量价与技术指标/`

## 3. 实操组合逻辑（非圣杯）

常见专业做法是**多周期 + 共振**：

1. 大级别定方向（周/日趋势）  
2. 小级别找点位（回调、突破）  
3. 量价确认  
4. 与风控位绑定（ATR 止损、时间失效）  

## 4. 量化化时必须做的事

- 固定规则、禁止事后画线解释  
- 样本外与多市场检验  
- 成本与 T+1 约束下是否仍有边缘  
- 与基本面/因子组合时做共线性与衰减监控  

## 5. 产品启示

- 默认展示「状态描述」（趋势/震荡、超买超卖）而非「必买必卖」  
- 指标参数可解释、可回测；提供稳健默认参数  
- 场景引擎中：突破策略与回归策略的建议模板应分开
