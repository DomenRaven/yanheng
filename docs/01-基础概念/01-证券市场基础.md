# 证券市场基础

> 一句话：股票是公司所有权凭证；价格由供需与预期驱动，收益来自价格变动与分红，风险来自不确定性与流动性。

## 1. 核心对象

| 概念 | 说明 |
|------|------|
| 股票 / 股权 | 对公司净资产与剩余索取权的份额 |
| 债券 | 债权凭证，固收属性更强 |
| 基金 | 组合化投资工具（主动/被动/ETF） |
| 指数 | 市场或板块的统计代理（如沪深300） |
| 衍生品 | 期货、期权等，用于对冲或杠杆（散户需谨慎） |

## 2. 收益与风险的基本分解

对任意资产，超额收益常被写成：

\[
R_i - R_f = \alpha_i + \beta_i (R_m - R_f) + \varepsilon_i
\]

- **系统性风险**：无法靠分散消除（市场/宏观）  
- **特异性风险**：个股特有，组合可稀释  
- **Alpha**：相对风险模型的超额（可正可负，不稳定）  
- **Beta**：对市场的敏感度  

## 3. 价格形成的直觉

- 信息 → 预期现金流与折现率 → 估值 → 交易 → 价格  
- 短期价格噪音大；长期更贴近基本面（但不保证）  
- 流动性差时，价格发现弱，冲击成本高  

## 4. 投资 vs 投机 vs 量化

| 取向 | 核心问题 | 典型工具 |
|------|----------|----------|
| 价值投资 | 值不值 | 财报、护城河、DCF |
| 趋势/短线 | 何时动 | 量价、技术指标 |
| 量化 | 规则是否稳健 | 因子、回测、优化 |
| 配置 | 长期风险收益 | 资产配置、再平衡 |

产品应允许用户选择取向，而不是强塞单一风格。

## 5. 产品启示

- UI 要同时展示：**收益、风险、流动性、可交易性**  
- 任何「预测」旁必须有风险单位（波动、最大回撤、VaR）  
- 用指数作为默认基准，避免无相对表现的绝对收益幻觉
