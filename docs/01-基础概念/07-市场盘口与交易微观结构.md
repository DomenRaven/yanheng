# 市场盘口与交易微观结构

> 一句话：盘口回答「当下谁在什么价、以什么方式成交」；它是量价分析的微观层，也是识别可疑操盘的主要战场。

## 1. 层级地图

| 层级 | 对象 | 典型工具 |
|------|------|----------|
| 宏观价量 | K线、均线、日成交量 | 技术分析 |
| 中观分布 | 筹码、成交量分布 Volume Profile | 成本区 |
| **微观盘口** | 五档/十档、逐笔、委托队列 | 订单流 |
| 隐藏流动性 | 冰山单、暗池、大宗 | 机构执行 |

## 2. 核心名词拆解

### 2.1 官方/制度含义

| 名词 | 准确含义 |
|------|----------|
| 盘口 / 委托簿（Order Book） | 买卖挂单价格与数量 |
| 逐笔成交 / Tape | 已成交明细：价、量、主买主卖 |
| 集合竞价 | 开收盘集中撮合 |
| 大宗交易 | 大额协议成交，影响次日供给预期 |
| **港股暗盘** | 新股上市前特定暗盘交易机制（**≠ A股常规用语**） |
| Dark Pool（暗池） | 不展示完整报价的场外/替代交易场所（海外更常见） |

### 2.2 口语/软件常用但易混

| 名词 | 实务用法 | 注意 |
|------|----------|------|
| **暗盘（资金）** | 部分行情软件对「隐性挂单/大单意图」的代理指标 | 非交易所标准术语；算法不透明，不可神化 |
| **暗仓** | 指隐藏建仓意图或未充分暴露的持仓行为 | 可能指冰山单、分仓、大宗；需定义清楚 |
| 主力 / 庄 | 口语化优势资金方 | 分析上改用「大单、机构、游资」更可操作 |

### 2.3 订单流关键量

| 概念 | 含义 |
|------|------|
| 主动买 / 主动卖 | 吃对手盘的成交方向 |
| Delta | 主动买量 − 主动卖量 |
| 冰山单（Iceberg） | 只显示一小部分的大单 |
| 挂单墙 / 钓鱼单 | 大挂单恐吓或诱导，常伴随撤单 |
| 对倒 / 对敲 | 关联账户自买自卖制造量能假象（涉嫌操纵） |
| 吸筹 / 洗盘 / 派发 | 行为阶段假说（需多证据，不可单点认定） |

## 3. 「大单买 + 小单卖」可能含义（多假说）

| 假说 | 盘口特征倾向 | 风险含义 |
|------|----------------|----------|
| 吸筹 | 大单托底，价格不急拉，小单恐慌卖 | 中期或偏多，仍需位置与逻辑 |
| 对倒做量 | 量增价平、来回扫，账户行为异常 | 诱多风险高 |
| 边拉边出 | 大单拉升同时更高位派发 | 冲高回落风险 |
| 算法拆单 | 大单拆小，方向未必「大买小卖」表象 | 勿过度解读 |

**原则**：单一快照不足以判「庄」；要看持续时间、价位、换手、龙虎榜、公告与基本面。

## 4. 平级类别

- 技术分析（K线指标）  
- 资金流向（北向、融资、ETF）  
- 筹码分布  
- 合规监控（异常交易）  

## 5. 产品启示

- 术语词典中区分：港股暗盘 / 暗池 / 软件「暗盘指标」  
- 盘口模块输出「多假说 + 置信度低」而不是「主力吸筹确定」  
- 涉及操纵嫌疑时引导合规警示，不做教唆
