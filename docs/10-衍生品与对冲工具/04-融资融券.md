# 融资融券（两融）

> 一句话：融资是借钱做多放大杠杆；融券是借券做空/对冲；两融余额也是重要的市场情绪与资金面观测指标。

## 1. 基本机制

| 类型 | 逻辑 |
|------|------|
| 融资 | 向券商借钱买入标的，看多加杠杆 |
| 融券 | 向券商借入标的先卖出，待价格下跌后买回归还，赚取价差（做空） |

## 2. 核心风控参数

| 参数 | 含义 |
|------|------|
| 保证金比例 | 自有资金占交易金额的最低比例；2026-01-19 起沪深北交易所已将融资保证金比例下限由 80% 上调至 100%（存量合约按原规定执行），会随监管逆周期调节动态变化 |
| 维持担保比例 | \(= \text{担保物总价值} / \text{负债总额}\)；行业惯例警戒线约 150%、平仓线约 130%（监管底线），部分券商在 130% 之上另设更严格的"即时平仓线"（如 110%–115%），具体以各自券商两融合同为准 |
| 强制平仓 | 维持担保比例跌破下限且未及时补充担保物，券商有权强制平仓 |
| 合约期限 | 单笔融资融券合约通常最长不超过 6 个月，可展期 |
| 按日计息 | 持仓时间越长，利息成本越高 |

## 3. 制度演进要点（产品需注意时效性）

- 全面注册制后，注册制新股上市首日即可纳入融资融券标的，转融通标的同步扩容  
- 北交所已发布融资融券交易细则，总体比照沪深两融成熟模式（券源与流动性仍是现实约束）  
- 融券券源有限，机构常反映「想做的没券、有券的没意愿」，套保效率受限于券源结构  

## 4. 融资融券的场景化用法

| 场景 | 用法 |
|------|------|
| 波段加杠杆 | 短线放大收益（同时放大风险，不建议长期重仓扛单） |
| 融券对冲 | 高位震荡持仓时融券做空同标的/相关标的，对冲下行风险 |
| 事件套利 | 增发前融券卖出，价格下跌后买券还券（需合规与信息前瞻性核查） |
| 配对交易 | 融资买入低估标的 + 融券卖出高估的高相关标的 |
| 期现/ETF 套利辅助 | 与股指期货、ETF 折溢价套利组合使用 |

## 5. 风险清单（产品必须提示）

- 杠杆双向放大盈亏，极端行情下可能穿仓  
- 强制平仓具有非自愿性和不利时点风险  
- 利息成本随持仓时间累积，不适合长期死扛  
- 融券做空理论亏损无限（价格上涨无上限）  

## 6. 产品启示

- 涉及两融的建议必须显式标注杠杆倍数与强平线距离  
- 两融余额变化可作为市场情绪/资金面的辅助观测指标（非个股买卖直接信号）
