# 可转债

> 一句话：可转债 = 债券兜底 + 股票期权弹性；核心决策变量是转股价值与溢价率，T+0 属性使其成为国内独特的量化交易品种。

## 1. 核心要素

| 要素 | 含义 |
|------|------|
| 票面利率 | 债底收益（通常很低） |
| 转股价 | 约定的转换为正股的价格 |
| 转股价值 | \( = \text{正股价格} / \text{转股价} \times 100 \) |
| 转股溢价率 | \( = \text{转债价格} / \text{转股价值} - 1 \) |
| 下修条款 | 正股价格持续低于转股价一定比例时，公司可下修转股价（对持有人有利） |
| 强赎条款 | 正股价格持续高于转股价一定比例时，公司可强制赎回（倒逼转股） |
| 回售条款 | 正股价格持续低迷到一定阈值，持有人可回售给发行人 |

## 2. 定价逻辑

- 债底价值：按票面利率与市场利率折现的纯债价值（下限保护，非绝对保本，仍有信用风险）  
- 期权价值：正股波动率越高、剩余期限越长，期权价值越高  
- 溢价率为负（转债价格 < 转股价值）：存在「买转债→转股→卖正股」的套利空间（需考虑 T+1 正股卖出限制与转股到账时间）  

## 3. 独特交易属性

- **T+0**：当日可买卖（不同于正股 T+1），是少数可日内回转的场内品种  
- 波动通常大于纯债、小于正股（下有底、上不封顶的非对称收益特征）  
- 高价转债（远高于面值）股性强、风险接近正股；低价转债债性强、防御性更好  

## 4. 常见策略类型

| 策略 | 逻辑 |
|------|------|
| 低价可转债轮动 | 精选低价、剩余期限适中的转债，博弈债底保护+向上弹性 |
| 负溢价套利 | 溢价率为负时买转债转股卖正股锁价差 |
| 强赎博弈 | 正股逼近强赎线时的博弈与规避 |
| 打新/配债策略 | 优先配售权与上市首日溢价机会（需评估破发风险） |

## 5. 风险提示

- 信用风险：转债发行人仍可能违约（尤其民企、评级较低品种）  
- 强赎风险：忘记操作可能被低价强制赎回，造成损失  
- 流动性风险：部分小盘转债交易清淡，冲击成本高  
- 正股 T+1 限制下，转股后次日才能卖出正股，套利存在过夜风险  

## 6. 产品启示

- 转债模块必须展示：转股价值、溢价率、距离强赎/回售线的空间、信用评级  
- 强赎日历提醒是刚需功能（避免用户踏空强赎公告）
