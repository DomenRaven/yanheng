# 期货与股指衍生品

> 一句话：期货是双方对等履约的标准化远期合约；股指期货/期权是股票组合最主流的宏观对冲与套利工具。

## 1. 期货基础

| 概念 | 含义 |
|------|------|
| 标准化合约 | 数量、交割月份、质量标准统一 |
| 保证金交易 | 双方均缴纳，按比例（杠杆） |
| 逐日盯市 | 每日结算盈亏，保证金不足需追加 |
| 基差 | 现货价 − 期货价；基差收敛是期现套利的基础 |
| 升水 / 贴水 | 期货价高于/低于现货价 |

## 2. 股指期货与期权的核心用途

| 用途 | 逻辑 |
|------|------|
| 系统性风险对冲 | 持有股票组合 + 卖出股指期货，对冲市场 Beta 风险 |
| Alpha 剥离 | 对冲市场后，保留个股/组合的超额收益（市场中性策略基础） |
| 期现套利 | 期货升水过高时：融资买入成分股 + 卖出期货，收敛后平仓获利；贴水过多则反向操作 |
| 流动性管理 | 大资金调仓时用期货快速调整敞口，避免直接冲击现货 |

## 3. 期现套利机制简述

- 升水套利：期货价 > 现货 → 买入一篮子现货 + 卖空期货 → 价格收敛后同时平仓  
- 贴水套利：期货价 < 现货 → 融资买入期货标的、卖出期货头寸方向相反操作  
- 需考虑：融资成本、冲击成本、跟踪误差（用 ETF/一篮子股票复制指数的误差）  

## 4. 与融资融券的组合策略（简述）

- 融券对冲：做空个股/ETF 对冲组合下行风险  
- 券源对冲：券商用股指期货对冲融券出借的市场风险敞口（机构侧）  
- 配对交易：融资买入相对低估标的 + 融券卖出相对高估的高相关标的，赚取价差收敛  

## 5. 风险提示

- 期货保证金杠杆放大盈亏，逐日盯市可能引发连续追加保证金  
- 基差风险：对冲不是零风险，基差可能不按预期收敛  
- 普通个人投资者门槛高（资金、经验、适当性要求），不适合作为默认产品功能  

## 6. 产品启示

- 面向散户的产品应把期货/期权定位为**知识科普 + 风险认知**，而非直接建议裸操作  
- 若涉及组合风险对冲建议，可提示「理论上可用股指期货对冲，但需专业账户与理解保证金机制」
