# 期权基础与希腊字母

> 一句话：期权是「权利」不是「义务」；买方风险有限收益理论无限，卖方收益有限风险理论无限——希腊字母是拆解期权风险的标准语言。

## 1. 基础概念

| 概念 | 含义 |
|------|------|
| 认购期权 Call | 有权按约定价买入标的 |
| 认沽期权 Put | 有权按约定价卖出标的 |
| 权利金 Premium | 买方支付给卖方的期权价格 |
| 行权价 Strike | 约定的买卖价格 |
| 到期日 | 权利有效截止时间 |
| 实值/平值/虚值（ITM/ATM/OTM） | 行权价与标的现价的相对关系 |
| 内在价值 + 时间价值 | 期权价格的两个组成部分 |

### 期权 vs 期货

| 维度 | 期权 | 期货 |
|------|------|------|
| 权利义务 | 买方仅有权利、卖方有义务 | 双方对等义务 |
| 保证金 | 仅卖方缴纳 | 双方均缴纳 |
| 保证金性质 | 非线性（虚值小、实值大） | 线性 |
| 风险收益 | 买方有限风险/理论无限收益；卖方相反 | 双方对称 |

## 2. 希腊字母（风险敏感度）

| 希腊字母 | 衡量 | 直觉 |
|----------|------|------|
| Delta (Δ) | 标的价格变动 1 单位，期权价格变动量 | 近似「持有多少标的股数的等价敞口」 |
| Gamma (Γ) | Delta 对标的价格变化的敏感度 | 曲率风险，临近到期/平值时最大 |
| Vega (ν) | 隐含波动率变动的敏感度 | 波动率上升对期权买方有利 |
| Theta (Θ) | 时间流逝对期权价值的影响 | 买方每天被"侵蚀"的时间价值 |
| Rho (ρ) | 利率变动敏感度 | 通常影响较小，长期期权更明显 |

## 3. 基础策略（组合逻辑）

| 策略 | 结构 | 用途 |
|------|------|------|
| 备兑开仓 Covered Call | 持有正股 + 卖出认购 | 增强收益，牺牲上涨空间 |
| 保护性看跌 Protective Put | 持有正股 + 买入认沽 | 为持仓买保险，对冲下跌 |
| 牛市价差 | 买低行权价Call + 卖高行权价Call | 限定风险的看涨 |
| 熊市价差 | 买高行权价Put + 卖低行权价Put | 限定风险的看跌 |
| 跨式/宽跨式 | 同时买Call和Put | 押注大幅波动，方向不确定 |

## 4. 期权定价基础（Black-Scholes 直觉）

- 输入：标的价、行权价、到期时间、无风险利率、隐含波动率  
- **隐含波动率**是期权定价的核心变量，反映市场对未来波动的预期，可反推出「市场恐慌/平静」程度（如 VIX 类指数思想）  
- 期权定价高度非线性，散户直接裸买期权常年是负和游戏（时间价值损耗 + 波动率回落双重侵蚀）  

## 5. 产品启示

- 若产品涉及期权相关标的，应至少展示 Delta 等价敞口，避免用户误判杠杆  
- 教育优先于策略推荐：多数散户更适合备兑/保护性用法而非裸买卖方  
- 期权知识需强合规提示（适当性管理、开户门槛）
