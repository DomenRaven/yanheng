# 组合优化

> 一句话：优化器把「想法」变成「可执行权重」；约束与风险模型质量决定结果是否可上实盘。

## 1. 常见目标

| 目标 | 直觉 |
|------|------|
| 均值-方差效用最大 | 经典 Markowitz |
| 方差 / 追踪误差最小 | 指数增强、稳健配置 |
| 夏普近似最大 | 需谨慎估计 |
| 风险平价 | 风险贡献均衡 |
| CVaR 最小 | 关注尾部 |
| 最大化 Alpha − λ·风险 | 主动管理标准写法 |

## 2. 常见约束（产品应默认提供）

- 权重上下限、股票数量  
- 行业 / 风格偏离上限  
- 换手率上限（控制成本）  
- 禁止买入列表（ST、停牌、黑名单）  
- 现金比例、单票集中度  
- 多空与杠杆限制（散户通常多头现金账户）  

## 3. 工业工具链参考

- 米筐 RQOptimizer：与风险模型、白名单、指数增强场景结合  
- FactSet Portfolio Optimizer / 各类二次规划求解器  
- 开源：`cvxpy`、Riskfolio-Lib、部分 vectorbt PRO 能力等  

## 4. 数值与估计技巧

- 协方差收缩（Ledoit-Wolf 等）  
- 用因子风险模型降维  
- 对预期收益做收缩 / 观点融合（Black-Litterman）  
- 正则化与换手惩罚，避免解剧烈跳动  

## 5. 产品启示

- 「加仓/减仓」建议 = 目标组合 − 当前组合 的差分，并受换手约束  
- 给散户先提供规则化再平衡，再提供完整优化器  
- 每次优化输出：目标权重、主要约束是否绑定、预期风险变化
