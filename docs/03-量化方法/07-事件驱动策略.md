# 事件驱动策略

> 一句话：事件驱动策略押注「特定事件公布前后，价格会出现可统计的异常收益模式」；核心工具是事件研究法，关键风险是信息提前泄露与拥挤交易。

## 1. 常见事件类型

| 事件 | 潜在异常收益模式 |
|------|------------------|
| 财报发布（业绩超预期/不及预期） | 盈余公告后漂移（PEAD：Post-Earnings-Announcement Drift） |
| 指数调整（纳入/剔除） | 被动资金跟踪引发的买卖压力，纳入前后有统计规律 |
| 并购重组 | 收购方/被收购方股价异动，套利空间（并购套利） |
| 增发/配股 | 增发前后价格压力（见融资融券套利场景） |
| 股权激励/回购 | 管理层信心信号 |
| 解禁/大股东减持计划 | 供给冲击预期 |
| 主题催化事件（政策/科研突破） | 见 `../09-场景决策案例/02-题材催化与科技成果.md` |

## 2. 事件研究法（Event Study）基本框架

```text
1. 定义事件日 t=0 与估计窗口（事件前的正常收益基准）
2. 计算正常收益模型（如市场模型：r_i = α + β·r_m）
3. 计算异常收益 AR_t = 实际收益 - 预期收益
4. 累积异常收益 CAR = ΣAR_t（观察窗口内累加）
5. 统计检验 CAR 是否显著不为零
```

用于验证「这类事件是否真的存在可复制的超额收益」，而非直觉臆断。

## 3. 日历效应/季节性（事件驱动的特例）

| 效应 | 描述 | 注意 |
|------|------|------|
| 一月效应 | 部分市场年初小盘股表现偏强的历史统计现象 | 样本与市场结构依赖性强 |
| 月末/季末效应 | 机构调仓、指数再平衡带来的流动性扰动 | 需结合具体指数规则 |
| 节前效应 | A股历史上长假前部分行情特征 | 非稳定规律，需持续检验 |

**纪律**：日历效应属于「可能被套利掉」的公开模式，务必样本外检验，不可盲目信奉。

## 4. 并购套利简述

- 收购要约公告后，目标公司股价通常向要约价收敛但存在折价（反映交易失败概率与时间成本）  
- 策略：买入目标公司股票，赌交易顺利完成，赚取折价收敛的价差  
- 风险：监管未通过、交易方毁约、时间拖长侵蚀年化收益  

## 5. 风险与合规红线

- **不得利用未公开重大信息交易**（内幕交易违法）；事件驱动策略必须基于**公开信息**  
- 拥挤交易风险：热门事件类型的策略容易同质化，导致执行时价格已被计入  
- A股 T+1、涨跌停可能使事件当日无法及时建仓/离场，需纳入策略可执行性评估  

## 6. 产品启示

- 事件驱动信号必须标注「基于公开信息的统计规律，不构成内幕信息使用建议」  
- 与主题催化场景共享同一套「催化真实性 × 拥挤度」评估框架
