# 机器学习与深度学习（股票预测）

> 一句话：ML/DL 擅长非线性与多源特征，但金融信噪比低、非平稳；工程防泄漏与组合层风控比网络花样更重要。

## 1. 经典机器学习（仍很实用）

| 方法 | 典型用途 |
|------|----------|
| 线性 / Ridge / Lasso / Elastic Net | 可解释基线、因子加权 |
| 树模型：RF、XGBoost、LightGBM、CatBoost | 表格因子选股主力 |
| SVM / 核方法 | 小样本分类（逐渐少用） |
| 集成与 stacking | 提升稳健性，注意过拟合 |

## 2. 深度学习主流结构（2015–2025 综述趋势）

综合学术综述与近年 arXiv/期刊工作：

| 结构 | 捕捉什么 | 备注 |
|------|----------|------|
| RNN / LSTM / GRU | 时序依赖 | 经典但训练与长程依赖有限 |
| TCN | 因果卷积时序 | 并行较好 |
| Transformer / 金融变体 | 长程依赖、多资产注意力 | MASTER 等 |
| CNN | 局部形态、多品种图像化 | 常作混合部件 |
| GNN / GAT | 股票关系、产业链、行业图 | 结构信息；注意过平滑 |
| GAN / Diffusion | 数据增强、行情仿真 | 研究向，生产慎用 |
| LLM | 研报/新闻/情绪、公式化 Alpha 生成 | 解释与特征源；本身非交易圣杯 |

新兴方向示例：频域+时序融合、跨市场协同、LLM 生成 formulaic alpha 再喂给 Transformer、多智能体投研等。

## 3. 标签与任务设计（比模型更关键）

- 回归未来收益 / 波动  
- 分类涨跌（需阈值与成本对齐）  
- **学习排序**（更贴选股）  
- 分位数回归（预测分布而非点）  

## 4. 必须守住的工程纪律

- 严格时间切分与 Walk-forward  
- Point-in-time 特征；禁止未来函数  
- 防止公司间信息泄漏的错误标准化  
- 交易成本、涨跌停、停牌进入训练目标或后处理  
- 模型监控：PSI、IC 衰减、概念漂移  

## 5. 产品启示

- MVP：LightGBM/线性因子 → 再考虑 LSTM/Transformer  
- DL 输出进入**组合优化与风控**，不要直连「全仓买入」  
- LLM 适合：解释、研报摘要、因子假设生成；最终下决策仍需可回测信号
