# 量化交易总览

> 一句话：量化交易是把投资决策写成可重复规则/模型，并用数据验证与风控约束执行；它是方法面，可叠加基本面、技术面或另类数据。

## 1. 名词边界

| 词 | 含义 |
|----|------|
| 量化研究 | 因子、回测、归因 |
| 量化交易 / 程序化 | 计算机生成或执行指令 |
| 系统化交易 | 纪律执行，不一定高频 |
| 算法交易 | 强调拆单执行（TWAP/VWAP 等） |
| 高频交易 HFT | 极低延迟；监管与基建门槛高 |

## 2. 策略大类（下属）

| 大类 | 例子 |
|------|------|
| 多因子选股 | 价值/质量/动量等 |
| 时间序列 / 趋势 | CTA 风格、均线突破 |
| 均值回归 | 短反转、配对 |
| 事件驱动 | 财报、增发、主题催化量化 |
| 中性 / 对冲 | 市场中性、行业中性 |
| 做市与微观结构 | 需特殊权限与合规 |

## 3. 标准流水线（与产品架构对齐）

数据 → 特征 → 信号 → 组合 → 风控 → 执行 → 监控  

详见：`../07-产品设计启示/01-投研闭环架构.md`

## 4. 平级方法面

- 主观基本面、技术分析、宏观配置、主题博弈  
量化可服务以上任一，不是互斥宗教。

## 5. 与监管
