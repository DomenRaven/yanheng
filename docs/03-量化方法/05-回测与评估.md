# 回测与评估

> 一句话：回测是证伪工具不是印钞机；好的回测框架优先暴露策略为什么会失败。

## 1. 回测引擎类型

| 类型 | 代表 | 擅长 |
|------|------|------|
| 事件驱动 | backtrader、Zipline/LEAN | 路径依赖、订单逻辑 |
| 向量化 | vectorbt | 大规模参数扫描 |
| 平台托管 | 聚宽、米筐、QuantConnect | 数据+研究+部分实盘 |
| AI 投研平台 | Microsoft Qlib | 因子/ML 流水线 |

## 2. 必做真实性要素（A 股）

- 复权与公司行为  
- T+1、涨跌停、停牌、ST  
- 佣金、印花税、滑点、最小成交单位  
- 幸存者偏差：用当时股票池  
- 财报 Point-in-time  
- 禁止收盘偷看再「当日成交」的作弊（除非明确 cheat-on-close 并披露）  

## 3. 评估指标体系

**收益**：累计、年化、相对基准超额  

**风险**：波动、最大回撤、下行波动、VaR/CVaR  

**风险调整**：Sharpe、Sortino、Calmar、Information Ratio  

**交易**：换手、胜率、盈亏比、持仓天数、容量粗估  

**稳健**：分年、分市况、参数敏感性、Walk-forward、Monte Carlo 打乱  

## 4. 过拟合防控

- 先定假设再挖数据，记录实验次数  
- 保留真正未碰过的样本外区间  
- 复杂度惩罚；更少参数优先  
- 多空与多市场交叉验证  

## 5. 产品启示

- 每个上线信号绑定：回测报告模板 + 监控仪表盘  
- 对用户展示「回测假设」，避免把模拟当承诺  
- 研究侧用 vectorbt/Qlib，执行逻辑复杂时用事件驱动复核
