# 时序验证与标签工程（金融机器学习的地基）

> 一句话：金融机器学习的失败大多不是模型不够先进，而是标签定义得幼稚、验证方式漏了信息——这一篇比任何模型架构都更值得优先做对。来源锚点：Marcos López de Prado《Advances in Financial Machine Learning》(2018)。

## 1. 为什么标准交叉验证在金融数据上失效

- 标准 K-Fold 假设样本独立同分布（i.i.d.），但金融时序标签常常**跨越多个时间点**（如"未来5日收益"），相邻样本的标签区间会重叠  
- 若测试集样本的标签区间与训练集样本重叠，训练阶段就已经"看到"了测试期的信息 → 虚高的样本内表现，实盘大幅衰减  

## 2. 三重障碍标注法（Triple Barrier Method）

传统标注："T+N日后价格比现在高就标1"——**忽略路径依赖**（可能T+2日就已跌破止损出局）。

三重障碍法为每个样本设置三条边界，先触碰哪条决定标签：

| 障碍 | 含义 |
|------|------|
| 上障碍（止盈线） | 价格达到目标涨幅 → 标记为正 |
| 下障碍（止损线） | 价格达到目标跌幅 → 标记为负 |
| 纵向障碍（时间限制） | 到期未触碰止盈止损 → 按到期收益符号或标记为中性 |

- 更贴近真实交易的出场逻辑（谁都不会死拿到固定N天不管止损）  
- 障碍宽度是超参数：太宽 → 标签全部集中、样本失衡；太窄 → 全是噪声止损，失去过滤意义，需配合波动率动态设定宽度（如按ATR缩放）  

## 3. 元标签（Meta-Labeling）

- 核心思想：**"预测方向"和"决定是否下注"应是两个独立任务**  
- 结构：  
  1. 初级模型（Primary Model）：产生方向信号（可以是简单规则，如均线金叉，也可以是复杂ML模型）  
  2. 元模型（Meta-Model）：不预测涨跌，而是预测"初级模型这次信号可信吗"（二分类：批准/驳回）  
- 训练元模型的标签来自三重障碍法的结果：初级模型发出信号后，最终触碰止盈→元标签1，触碰止损或到期未达标→元标签0  
- 价值：把"选方向"和"控制下注强度/仓位"解耦，元模型的输出概率可直接映射为仓位大小（呼应 Kelly/仓位管理）  
- 局限：需要足够多的历史信号样本训练元模型，样本不足容易过拟合；障碍宽度设置本身是一门经验活  

## 4. Purged K-Fold 交叉验证 + Embargo

### 问题

普通 K-Fold 随机切分，训练集中可能混入与测试集标签区间重叠的样本 → 信息泄漏。

### 净化（Purging）

- 从训练集中剔除所有**标签区间与测试集标签区间有重叠**的样本  

### 禁运期（Embargo）

- 即使净化后，测试集之后紧邻的训练样本仍可能通过长周期特征（如60日均线）间接携带测试期信息  
- 在测试集之后再额外剔除一段数据（通常为特征窗口长度的一定比例）作为禁运缓冲  

### 流程

```text
1. 按时间顺序将数据切分为 K 组
2. 选取第 k 组为测试集
3. Purging：从训练集中剔除与测试集标签区间重叠的样本
4. Embargo：剔除测试集后紧邻的一段训练样本
5. 训练+评估，重复 K 次
```

- 进阶版：Combinatorial Purged CV（组合净化交叉验证），通过多种训练/测试组合方式估计策略表现的分布而非单一数值，缓解"选择性偏差"（不断调参直到某个切分表现好看）  

## 5. Walk-Forward（滚动前推）验证

- 与 Purged K-Fold 互补而非互斥：Walk-Forward 严格按时间推进（训练区间随时间滚动前移，永远只用过去预测未来），更贴近实盘部署节奏  
- 常见模式：固定窗口滚动 / 扩展窗口（anchored）滚动  
- 产品化建议：正式上线前的"最后一道关"应使用 Walk-Forward 复现，而非仅依赖 Purged K-Fold 的统计结果  

## 6. 标签设计的其他考量

| 任务类型 | 标签形式 | 适用场景 |
|----------|----------|----------|
| 回归 | 未来收益率/波动率数值 | 需要精细排序或风险预测 |
| 分类 | 涨/跌/中性（三重障碍） | 择时/交易信号 |
| 学习排序（Learning to Rank） | 横截面收益排名 | 选股（更贴合实际选股任务本质） |
| 分位数回归 | 预测收益分布而非点估计 | 风险管理、极端情形建模 |

## 7. 产品与工程启示

- 任何声称"胜率XX%"的信号，必须先说明其标签定义（简单固定期 vs 三重障碍）——两者不可比较  
- 回测/训练流水线必须内置 Purged K-Fold + Embargo 选项，作为默认而非可选项  
- 元标签思路可直接映射为产品的"信号强度/置信度"展示，而不是二元的"买/卖"
