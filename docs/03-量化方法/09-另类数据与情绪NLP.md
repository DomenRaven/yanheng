# 另类数据与情绪 NLP

> 一句话：另类数据试图捕捉「财务报表还没披露、但已经发生」的信息；文本情绪分析是国内应用最成熟的另类数据分支，价值和噪声并存。

## 1. 另类数据类型地图

| 类型 | 例子 | 潜在价值 |
|------|------|----------|
| 文本/舆情 | 新闻、公告、社交媒体、研报 | 情绪、事件早期信号 |
| 交易行为衍生 | 龙虎榜、大宗交易、北向资金、ETF申赎 | 资金面代理指标 |
| 供应链/产业数据 | 招聘数据、卫星图像（如车流/工地）、物流数据 | 高频验证产业面景气 |
| 消费者行为 | App下载/使用量、电商销量 | 消费类公司高频跟踪 |
| 政策文本 | 政府工作报告、产业政策文件 | 政策周期与产业面共振信号 |

## 2. 情绪 NLP 常见流程

```text
1. 数据采集：新闻/公告/社媒/研报
2. 预处理：去噪、分词、实体识别（关联到具体股票/行业）
3. 情绪打分：词典法（金融专用情感词典）或深度学习分类器
4. 聚合：个股/行业/市场级情绪指数
5. 与价格结合：情绪领先/滞后关系检验、事件研究
```

## 3. 常见应用

| 应用 | 说明 |
|------|------|
| 舆情热度 | 主题/概念火热程度的量化代理（呼应 `../01-基础概念/06-概念题材与主题投资.md`） |
| 财报电话会情绪 | 管理层措辞变化作为盈利质量辅助信号 |
| 突发事件监控 | 负面新闻早期预警（风险排雷） |
| LLM 增强 | 用大语言模型总结研报、生成结构化情绪/事件标签，甚至辅助生成公式化因子（见 `../03-量化方法/03-机器学习与深度学习.md`） |

## 4. 局限与风险

- 数据噪声大，需要大量清洗与去重（转发/水军/自媒体标题党）  
- 情绪滞后于价格 vs 领先于价格，因市场与事件类型而异，需实证检验而非假设  
- 另类数据获取与处理成本高，容易被过度神化为「信息差」  
- **舆情热度 ≠ 基本面兑现**：见主题生命周期，热度是拥挤度的代理，不是买入理由本身  

## 5. 产品启示

- 情绪指数应作为**辅助维度**，与产业面、财务面并列展示，而非独立决策依据  
- 舆情监控功能应聚焦「风险预警」（负面舆情早发现）与「拥挤度」，而非鼓励追热点  
- LLM 摘要类功能必须标注信息来源与时间戳，保证可追溯
