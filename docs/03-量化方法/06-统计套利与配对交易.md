# 统计套利与配对交易

> 一句话：统计套利押注「历史上稳定的价格关系会均值回归」；核心工程是选对、估对冲比、定阈值，失败模式往往是关系本身发生结构性断裂而非运气不好。

## 1. 核心思想

- 寻找两只或一篮子资产间历史上稳定的线性关系（价差/比值）  
- 当关系出现临时偏离，假设会收敛 → 建立多空头寸博弈收敛  
- 本质是**市场中性**：对冲掉共同的市场风险，只留下「关系是否回归」的特异性赌注  

## 2. 配对交易三部曲

### 第一步：选对（配对筛选）

| 方法 | 说明 |
|------|------|
| 距离法 | 价格标准化后欧氏距离最小的两只股票 |
| 相关法 | 收益率相关系数高 |
| 协整法（推荐） | Engle-Granger（单方程）/ Johansen（多变量向量误差修正）检验是否存在平稳线性组合 |

协整法更贴合本质：相关只是同涨同跌，协整才是「长期均衡关系」。

### 第二步：估对冲比

- 对数价格 OLS 回归：\(\log P_y = \alpha + \beta \log P_x + \varepsilon\)  
- \(\beta\) 即对冲比率（每买1份Y需要卖出的X份数）  
- 残差序列 \(\varepsilon_t\) 应体现均值回归特性（可用 Ornstein-Uhlenbeck 过程刻画半衰期）  

### 第三步：定阈值

- Z-Score：\(z_t = (\varepsilon_t - \bar\varepsilon) / \sigma_\varepsilon\)  
- 常见规则：\(|z| > 2\) 开仓，\(z\) 回归 0 附近平仓  
- 半衰期估计持仓周期，避免长期扛单等待「迟迟不回归」的关系  

## 3. 多资产扩展：PCA 残差法

- 对一篮子股票收益做主成分分析，提取市场/行业等共同因子  
- 残差部分（特异收益）若呈现均值回归特性，可构建市场中性的组合信号（Avellaneda & Lee 思路）  

## 4. 事件驱动型统计套利变体

- 可转债负溢价套利（见 `../10-衍生品与对冲工具/03-可转债.md`）  
- 融资融券配对交易（融资买低估、融券卖高估的高相关标的）  
- ETF 折溢价套利（见 `../10-衍生品与对冲工具/05-ETF与套利机制.md`）  

## 5. 失败模式（历史教训）

| 案例类型 | 教训 |
|----------|------|
| 关系结构性断裂 | 行业格局变化、政策冲击导致「均值」本身漂移，不再回归 |
| 杠杆叠加流动性危机 | 极端行情下多个统计套利盘同时平仓，价差短期恶化更剧烈（类似 1998 LTCM、2007 Quant Quake 教训） |
| 过度拟合的配对 | 历史相关是巧合而非真实经济联系 |

## 6. A股实务约束

- T+1 限制日内配对回转的灵活性（无法同时当日双向平仓做空正股）  
- 融券券源有限，做空腿常受限（可转债 T+0 属性可部分替代）  
- 交易成本、印花税需纳入阈值设定，否则理论有效但实盘无利可图  

## 7. 产品启示

- 配对策略上线前必须做协整稳定性检验与多子样本回测  
- 设定「关系失效」监控（协整关系滚动检验），触发后自动降权或停用  
- 向用户展示时应明确「市场中性≠零风险」
