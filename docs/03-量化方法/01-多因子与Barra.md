# 多因子模型与 Barra 风险模型

> 一句话：多因子把收益拆成可解释的共同驱动；Barra 类模型用结构化暴露估计风险，是组合优化与归因的工业标准思路。

## 1. 多因子收益分解（一般式）

\[
r_j = \sum_k X_{jk} f_k + e_j
\]

- \(X_{jk}\)：股票 \(j\) 对因子 \(k\) 的暴露  
- \(f_k\)：因子收益  
- \(e_j\)：特异收益  

因子类型：

- **行业因子**  
- **风格因子**：Size、Value、Momentum、Volatility、Liquidity、Quality、Growth、Dividend 等  
- **Alpha 因子**：试图预测残差或超额的选股信号  

## 2. 标准投研流程（金工实务）

1. 数据清洗：复权、停牌、ST、财务对齐  
2. 去极值 / 标准化 / 中性化（行业、市值）  
3. 单因子检验：IC、RankIC、分层回测、换手  
4. 因子正交与去冗余（含与风险因子相关）  
5. 合成：线性加权或 ML（LightGBM/XGB 等）  
6. 组合：约束优化（行业偏离、换手、个股权重）  
7. 归因：收益与风险拆到因子  
8. 监控：衰减、拥挤、风格漂移  

## 3. Barra 思路的产品价值

- 用低维因子协方差近似高维股票协方差  
- 控制「不想要的暴露」（如过度小盘、高波动）  
- 区分：**赚的是 Alpha 还是踩对了风格**  

国内券商金工常复现 CNE5/CNE6 风格大类（Size、Volatility、Liquidity、Momentum、Quality、Value、Growth、Dividend Yield 等，具体以数据可得性裁剪）。

## 4. 因子评价核心指标

| 指标 | 含义 |
|------|------|
| IC | 因子值与下期收益相关系数 |
| RankIC | 排序相关，更稳健 |
| IR | IC 均值 / IC 标准差 |
| 多空收益 | 顶底层组合收益差 |
| 衰减 | IC 随持有期下降速度 |
| 换手 | 实盘成本相关 |

## 5. 产品启示

- MVP 可用「精简风格 + 少量 Alpha」；先归因再复杂 ML  
- 建议卡片展示主要暴露与「风险来源」  
- 把拥挤与衰减做成一等公民功能
