# 统计与时间序列方法

> 一句话：在深度学习之前，稳健的时序与波动模型仍是风险预测与基线策略的主力。

## 1. 收益与波动的基础统计

- 收益分布：厚尾、偏度、峰度；正态假设常不足  
- 波动聚集：大波动后常跟大波动（ARCH/GARCH 家族）  
- 自相关：收益率弱自相关，但平方/绝对收益常有自相关  

## 2. 常用模型清单

| 族 | 代表 | 用途 |
|----|------|------|
| 趋势/平滑 | MA、EMA、Holt-Winters | 基线、特征 |
| 经典时序 | ARIMA、SARIMA | 短期建模（金融上单独预测价格较弱） |
| 波动 | GARCH、EGARCH、GJR-GARCH | 波动率预测、仓位缩放 |
| 状态 | HMM、马尔可夫区制 | 牛熊/波动区制识别 |
| 协整 | Engle-Granger、Johansen | 配对交易 |
| 滤波 | Kalman | 动态 Beta、状态估计 |
| 频谱 | FFT / 小波 | 周期与多尺度特征（学术与部分量化在用） |

## 3. 与交易的连接方式

- **波动目标仓位**：目标波动 / 预测波动  
- **区制切换**：趋势策略仅在趋势区制启用  
- **配对/统计套利**：需严格成本与退市/政策风险控制（A 股融券等约束）  

## 4. 产品启示

- 风险模块优先上 GARCH/EWMA 波动，而不是一上来深度模型  
- 「市场状态」可作为场景引擎的一级输入  
- 所有时序特征必须防泄漏（只用 t 及以前）
