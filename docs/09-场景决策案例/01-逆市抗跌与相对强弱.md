# 场景：大盘跌而个股仍涨 —— 卖不卖？

> 一句话：先判断是「真相对强势」还是「补跌延迟」；再对照持仓逻辑与风险预算，而不是只因「逆市」就无脑持有或无脑卖出。

## 1. 场景拆解

| 元素 | 概念 |
|------|------|
| 大盘跌 | 市场 Beta 为负的环境 |
| 个股涨/抗跌 | 相对强弱 RS 高，或低 Beta，或独立催化 |
| 决策 | 持有 / 减仓兑现 / 清仓 |

## 2. 理论工具包

- **RS 相对强度**（个股收益 − 基准收益；或价格比）≠ RSI  
- **Alpha / 残差**：相对风险模型的超额  
- **Beta**：是否只是低敏感  
- 产业/公司独立利好 vs 情绪抱团  
- 止盈规则、回撤与集中度  

## 3. 判断流程（产品可落地）

```text
1. 是否有独立逻辑？（业绩/订单/主题受益清晰）
   否 → 提高「补跌」先验 → 倾向减仓保护
2. RS 是否持续多日/多周，而非单日脉冲？
   否 → 倾向当作噪音
3. 相对板块是否也强？仅强于大盘但弱于行业？
4. 估值与涨幅是否已透支逻辑？
5. 账户：该票是否过大？大盘系统性风险是否触发组合熔断？
6. 失效条件：跌破关键均线/失去相对强度/逻辑证伪 → 预置卖出
```

## 4. 常见结论模式

| 情形 | 更合理动作 |
|------|------------|
| 真龙头 + RS 持续 + 逻辑在 | 持有或持有+移动止盈 |
| 逆市但无逻辑、量能怪异 | 减仓/退出 |
| 大盘系统性崩塌、流动性危机 | 优先降组合风险，个股故事次之 |
| 大涨后逆市续涨至高潮 | 分批兑现，而非「还能涨」加仓 |

## 5. 相关平级场景

- 大盘涨个股不涨（相对弱势）  
- 板块跌个股独涨  
- 指数抗跌但广度很差（仅少数权重股支撑）
