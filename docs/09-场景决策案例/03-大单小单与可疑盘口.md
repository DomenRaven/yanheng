# 场景：大额买入同时大量小单卖出 —— 风险、操盘与买卖

> 一句话：该盘口结构存在多种竞争性假说（吸筹/对倒/边拉边出/算法拆单）；应用多证据降低误判，并把「操纵嫌疑」交给合规边界，而不是当作稳赚信号。

## 1. 现象拆解

| 观察 | 可能度量 |
|------|----------|
| 大批大额买入 | 大单主动成交、大单净额 |
| 许多小股被卖出 | 小单主动卖、散户侧抛压 |
| 价格路径 | 上涨 / 平盘放量 / 冲高回落 |

## 2. 竞争性假说（必须并列）

| 假说 | 更吻合的附加证据 | 行动倾向 |
|------|------------------|----------|
| 优势资金吸筹 | 持续时间长、价不急拉、事后筹码集中 | 观望确认或小仓，非整仓追 |
| 对倒做量诱多 | 量增价平、来回扫、关联账户特征 | 回避，防接盘 |
| 拉高派发 | 高位大单拉、同时更高/旁路卖出 | 减仓/不追 |
| 算法/被动拆单 | 无稳定「大买小卖」叙事 | 降低盘口权重 |
| 利好传闻分歧 | 公告将至、舆情分裂 | 等落地或降仓赌消息 |

## 3. 风险清单

- **信息风险**：你看到的是滞后或被污染的盘口代理  
- **操纵与异常交易**：对倒、虚假申报等违法；跟风可能接盘  
- **流动性幻觉**：放量不可持续  
- **行为风险**：把「像有主力」当成买入许可证  

## 4. 产品决策流程

```text
盘口异常 → 标记「低置信多假说」
  → 检查：位置(高/低)、主题阶段、基本面、龙虎榜/公告
  → 若高位+高潮+证据冲突 → 默认不追、持仓者减仓评估
  → 若低位+逻辑在+持续吸筹特征 → 最多试仓 + 严格失效条件
  → 任何「必是庄家吸筹」话术 → 禁止输出
```

## 5. 与合规

识别可疑模式用于**自我保护与风控**，不等于指控；产品文案避免教用户参与操纵或「跟庄秘籍」。
