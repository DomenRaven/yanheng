# 场景：行业突破 / 概念火热 —— 买还是抛？

> 一句话：催化要拆成「真伪 × 映射纯度 × 生命周期阶段 × 拥挤与估值」；火热本身不是买入理由，也经常是兑现卖出理由。

## 1. 场景拆解（以机器人、商业火箭回收为例）

| 信息 | 可能含义 |
|------|----------|
| 科研成果/进展 | 技术里程碑，未必短期收入 |
| 概念火热 | 注意力与资金拥挤上升 |
| 相关上市公司 | 映射有强有弱（主营 vs 蹭概念） |

## 2. 理论工具包

- 主题生命周期（萌芽→高潮→退潮）  
- 事件研究：利好公布后的平均异常收益常前移  
- 产业面：商业化路径、订单、产能  
- 拥挤度：换手、估值分位、舆情热度  
- 行为：FOMO、羊群  
- 「买预期、卖事实」的交易规律（非定理，但是高频经验）  

## 3. 决策矩阵

| 阶段 \ 映射 | 高纯度（主营相关） | 低纯度（蹭概念） |
|-------------|--------------------|------------------|
| 萌芽/扩散早期 | 可研究建仓/试仓 | 谨慎或不参与 |
| 高潮全民热议 | 倾向减仓兑现 | 优先回避/卖出 |
| 退潮分化 | 留业绩兑现者 | 清仓纯叙事 |

## 4. 买入前强制问题

1. 这条进展如何变成**收入与利润**？多久？  
2. 公司是否真有卡位？还是标题映射？  
3. 股价已涨多少？隐含了多乐观情景？  
4. 若明天证明是「仅概念」，下跌空间？  
5. 仓位是否压过风险预算？  

## 5. 抛出/减仓触发

- 利好落地但股价冲高回落（利好出尽）  
- 跟风股补涨而龙头滞涨  
- 换手与估值进入历史极端  
- 逻辑证伪（进度不及预期、对手技术路线胜出）
