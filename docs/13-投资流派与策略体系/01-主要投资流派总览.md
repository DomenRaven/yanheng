# 主要投资流派总览

> 一句话：不存在"最好"的流派，只有和你的资金属性、时间精力、心理承受力匹配的流派——理解流派谱系有助于产品做"千人千面"的建议风格。

## 1. 流派全景图

```text
按分析依据分：
├── 基本面驱动：价值投资、成长投资、GARP、困境反转
├── 技术面驱动：趋势跟踪、波段交易、形态交易
├── 量化驱动：多因子、统计套利、CTA、量化多空
├── 宏观驱动：全球宏观对冲
├── 事件驱动：并购套利、困境证券、特殊情况投资
└── 混合/多策略：跨流派配置

按持仓周期分：
├── 长期投资（年级别）：价值/成长
├── 中期波段（周-月级别）：趋势跟踪、主题投资
├── 短期交易（日-周级别）：技术交易、量化择时
└── 超短线/高频（分钟级以下）：做市、高频套利（个人基本不可及）
```

## 2. 流派对照表

| 流派 | 核心逻辑 | 代表方法 | 适配人群 |
|------|----------|----------|----------|
| 价值投资 | 买价格低于内在价值的资产 | DCF/PB-ROE、安全边际 | 有耐心、能忍受短期跑输 |
| 成长投资 | 买能持续高速增长的公司 | PEG、赛道分析 | 能承受高波动、看重远期空间 |
| GARP | 以合理价格买成长（价值+成长折中） | PEG≈1 附近筛选 | 兼顾安全边际与成长性 |
| 趋势跟踪 | 顺势而为，截断亏损让利润奔跑 | 均线系统、DMI、动量因子 | 能严格执行纪律 |
| 量化多因子 | 多因子模型统计选股 | Barra、机器学习选股 | 依赖系统化工具/数据 |
| 量化多空/市场中性 | 对冲市场Beta，赚取Alpha | 统计套利、配对交易 | 追求低相关性收益 |
| CTA（商品交易顾问） | 期货趋势/套利，多品种多周期分散 | 主观CTA/量化CTA | 追求与股票低相关的对冲配置 |
| 宏观对冲 | 押注宏观趋势（利率/汇率/大类资产） | 美林时钟、全天候 | 对宏观有系统认知 |
| 事件驱动 | 特定事件的确定性/概率错误定价 | 并购套利、可转债套利 | 关注公司行为与公告 |

## 4. 产品启示：流派化的建议风格

- 用户画像应包含「流派偏好」（价值型/趋势型/量化型/宏观型），影响建议措辞与指标权重  
- 同一只股票，不同流派视角结论可能相反（如高PE成长股：价值投资者看空、成长投资者看多）→ 产品应显式标注「基于哪种流派视角」，避免混淆用户  
- 避免把所有流派工具一股脑塞给用户，应有清晰的「流派身份」引导
