# 趋势跟踪、CTA 与宏观对冲

> 一句话：这三类流派共同点是不预测"对不对"，而是等市场证明趋势方向后顺势而为，用严格止损控制"猜错"的成本。

## 1. 趋势跟踪（Trend Following）

- 核心信念：趋势一旦形成会有惯性延续（与有效市场假说存在张力，行为金融的动量效应提供部分学术支撑）  
- 常用工具：均线系统、DMI/ADX（衡量趋势强度）、唐奇安通道突破  
- 纪律：**严格止损 + 让利润奔跑**（不对称的盈亏比弥补胜率不足）  
- 弱点：震荡市中频繁被"假突破"打止损（见 `../08-量价与技术指标/03-趋势与偏离类指标.md` 中 ADX 过滤逻辑）  

## 2. CTA（商品交易顾问）策略

| 分类 | 特征 |
|------|------|
| 主观CTA | 依赖产业供需、宏观政策、情绪等定性判断，波动大、可能有爆发式收益也可能大幅回撤 |
| 量化CTA | 覆盖多品种（黑色/有色/农产品/能源等）、多周期（高中低频）分散，净值曲线更平滑，追求"赚钱概率"的稳定发挥 |

- CTA 与股票、债券相关性通常较低，是组合分散化的重要工具（呼应全天候策略思想）  
- 个人投资者主要通过公募/私募 CTA 产品间接参与，直接操作期货门槛高、风险大  

## 3. 宏观对冲（Global Macro）

- 押注宏观趋势：利率、汇率、大宗商品、股指之间的联动关系  
- 工具箱：利率衍生品、外汇远期、股指期货/期权、大类资产轮动（见 `../11-宏观与大类资产配置/`）  
- 典型思路：先形成宏观判断（如"某国货币政策转向"），再选择流动性最好、风险收益比最优的工具表达该观点  

## 4. 三者的组合价值（组合视角）

```text
股票（权益Beta） + 债券（利率Beta） + CTA/宏观对冲（趋势/宏观Alpha，低相关）
= 更平滑的组合净值曲线（全天候思想的实务近似）
```

## 5. 产品启示

- 组合诊断可提示"当前持仓是否过度集中于单一流派/资产类别的方向性赌注"  
- 趋势跟踪类建议必须内置止损规则展示，不能只给"追涨"信号而不给"止损"信号  
- 面向进阶用户可科普 CTA/宏观对冲作为组合分散工具的角色，而非鼓励直接参与期货
