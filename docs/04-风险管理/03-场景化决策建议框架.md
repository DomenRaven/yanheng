# 场景化决策建议框架

> 一句话：专业建议 = f(市场状态, 标的信号, 账户状态, 约束, 用户偏好)；缺任何一项都会变成口号式荐股。

## 1. 五维输入

1. **市场状态**：趋势/震荡、波动区制、流动性、风格  
2. **标的信号**：基本面、技术面、因子/ML、舆情（可冲突）  
3. **账户状态**：现金、持仓、浮盈亏、集中度、相关度  
4. **约束**：T+1、涨跌停、黑名单、合规、成本  
5. **用户偏好**：期限、风险承受、禁止行业、交易频率  

## 2. 输出动作集合（枚举）

`观望 | 建仓 | 加仓 | 减仓 | 清仓 | 止损 | 止盈 | 再平衡 | 降低风险敞口`

每条输出强制字段：

- action、size_range、horizon、confidence  
- reasons[]（可追溯）  
- risks[]、invalid_if[]（失效条件）  
- alternatives[]（若约束冲突）  

## 3. 典型场景矩阵（摘要）

| 场景 | 常见误区 | 更专业处理 |
|------|----------|------------|
| 空仓 + 强信号 | 直接满仓 | 分批建仓 + 风险预算 |
| 浮盈较大 | 舍不得卖 | 计划止盈/移动止损 + 税务/成本 |
| 浮亏 | 补仓摊薄 | 先检验逻辑是否仍成立，否则止损 |
| 信号冲突 | 平均掉 | 展示冲突，降低置信度或观望 |
| 高波动市 | 照常交易 | 降杠杆/降仓，提高现金 |
| 涨停买不进 | 追次日 | 评估缺口风险与替代标的 |
| 临近大事件 | 赌消息 | 事件风险提示与仓位上限 |

## 4. 决策优先级（建议）

1. 合规与可交易性  
2. 生存风控（回撤/VaR/集中度）  
3. 账户结构健康  
4. 信号质量  
5. 收益增强  

## 5. 产品启示

- 用状态机实现建议，而不是 if 指标金叉 then 买入  
- 所有建议可回放：当时输入快照 → 输出  
- 把「观望」视为一等动作，降低过度交易
