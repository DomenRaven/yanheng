# 压力测试与情景分析

> 一句话：VaR 回答「正常市场下大概会亏多少」，压力测试回答「黑天鹅真来了会亏多少」——两者互补，缺一不可。

## 1. 与 VaR/CVaR 的关系

| 方法 | 回答的问题 | 局限 |
|------|------------|------|
| VaR/CVaR | 正常统计分布下的潜在损失 | 对极端尾部事件低估（假设历史会重演） |
| 压力测试 | 特定极端情景下的损失 | 情景设定的主观性、无法穷举所有黑天鹅 |
| 情景分析 | 多个假设性宏观/市场情景下的组合表现 | 需要合理的情景库与传导模型 |

## 2. 情景设计的两条路径

| 路径 | 说明 | 例子 |
|------|------|------|
| 历史情景法 | 复用历史真实危机的市场冲击幅度 | 2015年股灾式流动性冲击、2018年贸易摩擦冲击 |
| 假设情景法 | 人为构造尚未发生但合理的冲击 | 「十年期利率骤升300bp」「核心持仓行业政策骤紧」 |

## 3. 压力测试流程（可产品化）

```text
1. 识别风险因子：利率、汇率、行业政策、个股特有事件
2. 设定冲击幅度：轻度/中度/重度三档情景
3. 传导模型：风险因子 → 个股/组合收益的映射（可用因子暴露/Beta近似）
4. 传导校准：结合历史 Beta/因子暴露校准冲击传导路径
5. 结果分析：组合损失、最大回撤、保证金/维持担保比例是否触及平仓线
6. 应对预案：仓位上限、止损规则、对冲工具预案
```

## 4. 常见压力情景类别（覆盖多风险因子协同冲击）

| 情景 | 涉及风险 |
|------|----------|
| 系统性市场崩盘（如「股债商三杀」） | 市场风险 + 流动性风险 |
| 重仓行业政策骤然收紧 | 产业面风险（呼应 `../01-基础概念/05-产业面与行业分析.md`） |
| 重仓个股财务暴雷/退市风险触发 | 信用/特质风险 |
| 融资融券账户维持担保比例逼近平仓线 | 杠杆风险 |
| 流动性枯竭（无法以合理价格平仓） | 流动性风险 |

## 5. 逆向压力测试

- 传统压力测试：给定情景 → 算损失  
- 逆向压力测试：先设定「不可接受的损失阈值」→ 反推需要多大的冲击才会触发 → 帮助识别组合最脆弱的风险点  

## 6. 产品启示

- 组合诊断应包含至少 3 档压力情景（轻度/中度/重度）的模拟损失展示  
- 融资融券用户必须看到「维持担保比例在不同压力情景下的变化」  
- 压力测试结果应直接联动仓位建议（如提示降杠杆、加对冲）
