# 杠杆与保证金管理

> 一句话：杠杆不改变期望收益的方向，只放大方差——保证金管理的本质是防止「本该扛过去的正常波动」演变成「被迫平仓的永久性损失」。

## 1. 杠杆的数学直觉

- 2倍杠杆：标的涨10%，权益涨约20%（不计利息/费用）；标的跌10%，权益跌约20%  
- 杠杆下的最大回撤是非线性放大的：本金亏损50%需要上涨100%才能回本，杠杆越高这个「回本鸿沟」越陡峭  

## 2. A股主要杠杆渠道

| 渠道 | 杠杆机制 |
|------|----------|
| 融资融券 | 见 `../10-衍生品与对冲工具/04-融资融券.md` |
| 股票质押 | 大股东质押股票融资，平仓线触及可能引发连锁减持压力 |
| 场外配资（不合规/高风险） | 缺乏监管保护，历史上是多次踩踏行情的放大器，应明确提示远离 |
| 期货/期权保证金交易 | 见 `../10-衍生品与对冲工具/02-期货与股指衍生品.md` |

## 3. 维持担保比例与强平机制（融资融券为例）

\[
\text{维持担保比例} = \frac{\text{担保物总市值}}{\text{融资融券负债总额}}
\]

| 区间（行业惯例，具体以各券商规则为准） | 状态 |
|-----------------------------------|------|
| 高于警戒线（行业惯例常见 150%） | 正常 |
| 警戒线与平仓线之间 | 预警，需关注补充担保物 |
| 低于平仓线（监管底线 130%） | 可能触发强制平仓 |

**核验说明（2026-08 复核）**：证券公司并无统一的单一强平线，而是各自设定，130% 是行业公认的最低平仓线参考，150% 是常见的警戒线；部分券商已在 130% 之上另设更严格的"即时平仓线"（例如 110%–115%），触及后需在次一交易日日终前补足，否则可被强制平仓——具体以各自开户券商的两融合同条款为准，产品中不应写死统一数字。此外，2026-01-19 起沪深北交易所已将投资者融资买入证券时的融资保证金比例下限由 80% 上调至 100%（即新开合约最高杠杆恢复至理论1倍，此前一度放宽），存量合约按原规定执行，体现了保证金比例本身也会随监管逆周期调节而变化。

**关键提醒**：强平通常发生在最不利的时点（下跌途中），进一步加剧亏损，且非自愿。

## 4. 仓位与杠杆管理纪律

| 原则 | 说明 |
|------|------|
| 杠杆与波动率成反比 | 标的波动率越高，可承受的杠杆倍数应越低（呼应凯利公式思想，见 `../04-风险管理/02-仓位与资金管理.md`） |
| 预留保证金缓冲 | 不满仓加杠杆，为追加保证金留出空间 |
| 设定强制降杠杆规则 | 维持担保比例跌破自定义阈值（高于券商强平线）主动减仓 |
| 避免杠杆叠加杠杆 | 如用融资资金买入本身高波动的杠杆型产品 |

## 5. 产品启示

- 涉及两融/衍生品的仓位建议必须显示：当前杠杆倍数、距离预警线/平仓线的价格空间  
- 压力测试模块（见 `07-压力测试与情景分析.md`）应联动杠杆账户，模拟极端下跌对维持担保比例的冲击  
- 严禁产品功能诱导或暗示场外配资等不合规杠杆渠道
