# 绩效与风险指标族：回撤 · 波动 · 夏普及平级

> 一句话：用同一套指标评价策略与持仓——收益要经风险调整；最大回撤管「活得下去」，夏普管「每单位波动的补偿」。

## 1. 用户点名概念

### 最大回撤 Max Drawdown (MDD)

- 定义：净值从历史峰值到谷底的最大跌幅比例  
- 相关：回撤持续期、水下时间、平均回撤  
- 产品：账户熔断、策略下线阈值常锚定 MDD  

### 波动率 Volatility

| 类型 | 说明 |
|------|------|
| 历史波动 | 过去收益标准差（可年化） |
| 已实现波动 | 高频收益构造 |
| 隐含波动 | 期权市场定价（标的有期权时） |
| ATR | 价格波幅，常用于止损距离 |

高波动 → 同等仓位下回撤更大；仓位应反比缩放。

### 夏普比率 Sharpe Ratio

\[
\text{Sharpe} \approx \frac{\mathbb{E}[R-R_f]}{\sigma(R)}
\]

- 优点：流行、可比  
- 缺点：惩罚上行波动；非正态时误导；样本短不稳定  
- 注意：回测夏普常被高估（过拟合、成本低估）  

## 2. 平级指标（必须补齐）

| 指标 | 侧重点 |
|------|--------|
| Sortino | 只惩罚下行波动 |
| Calmar | 年化收益 / \|MDD\| |
| Information Ratio (IR) | 超额 / 追踪误差 |
| Beta / Alpha | 相对市场 |
| Omega | 收益分布阈值思想 |
| VaR / CVaR | 尾部损失（见专章） |
| 胜率 · 盈亏比 · 期望值 | 交易层 |
| 换手率 | 成本与容量 |

## 3. 组合阅读法

- 高夏普 + 深回撤：可能收益路径陡峭，体验差  
- 低波动 + 低夏普：可能过于保守或无 Alpha  
- 只看收益不看 MDD/波动：产品禁止作为唯一展示  

## 4. 产品启示

- 持仓页默认：收益、波动、MDD、夏普/索提诺、相对基准  
- 建议引擎用「风险预算剩余」而非口头「感觉还能加」
