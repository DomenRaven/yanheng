# 合规与程序化交易监管

> 一句话：辅助分析可以很智能；一旦涉及自动下单与程序化，就必须按监管把它当「受控系统」而不是玩具。

## 1. 产品形态与合规梯度

| 形态 | 风险 | 建议 |
|------|------|------|
| 纯分析/教育工具 | 较低 | 免责声明、不承诺收益 |
| 给出个性化建议 | 中 | 避免代客决策表述；适当性提示 |
| 智能投顾 | 高 | 持牌合作、适当性、信息披露 |
| 自动程序化交易 | 高 | 报告、监控、异常交易防控、券商协同 |

## 2. 程序化监管关键词（中国）

- 证监会《证券市场程序化交易管理规定（试行）》（2024）  
- 沪深北交易所《程序化交易管理实施细则》（2025 落地实施）  
- 报告制度、会员前端管控、异常交易监控  
- 高频交易额外要求与差异化管理导向  
- 强调公平、系统安全、防止操纵与异常波动贡献  

细则关注的异常类型包括但不限于：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交等。

## 3. 中基协等口径提醒

公开解读强调：量化并不享有 T+0 特权；融券变相 T+0 等通道已被加强规范。产品叙事勿传播制度谣言。

## 4. 工程合规清单

- [ ] 用户协议与风险揭示  
- [ ] 建议日志可审计  
- [ ] 速率与撤单限制（若自动下单）  
- [ ] 异常行为自检  
- [ ] 禁止诱导「稳赚」「跟庄」话术  
- [ ] 数据源版权与再分发合规  
- [ ] 个人信息与账户数据安全  

## 5. 产品启示

- MVP 默认「人确认下单」  
- 文案审查流程与模型输出同等重要  
- 未来若对接券商，优先合规友好的中低频策略
