# 流动性风险与信用风险

> 一句话：亏钱是市场风险，卖不出去是流动性风险，对手方/发行人违约是信用风险——三者常在危机中相互放大，个人投资者最容易忽视后两者。

## 1. 流动性风险（个人投资者视角）

| 类型 | 表现 |
|------|------|
| 市场流动性风险 | 小盘/冷门股买卖价差大、大单冲击成本高，想卖卖不出理想价格 |
| 融资流动性风险 | 融资融券账户维持担保比例不足，需追加保证金但资金调不出来 |
| 时点流动性风险 | 涨跌停/停牌导致无法按计划止损离场（A股特有，见 `../01-基础概念/02-A股市场制度.md`） |

### 衡量代理指标

- 买卖价差（Bid-Ask Spread）  
- 换手率 / 成交量绝对水平  
- 大宗交易折价率（折价越深，说明大额流动性溢价要求越高）  
- 流通市值与日均成交额的比值（衡量建仓/离场对价格的潜在冲击）  

## 2. 信用风险（个人投资者视角）

| 场景 | 信用风险来源 |
|------|--------------|
| 持有可转债 | 发行人偿债能力（尤其民企、低评级品种） |
| 持有债券基金/理财 | 底层债券发行人违约 |
| 融资融券 | 对手方（券商）信用与自身账户风险 |
| 场外/结构化产品 | 交易对手违约风险 |

- 关注信用评级变化、评级展望下调、担保物质量  

## 3. 机构侧概念（了解即可，便于理解监管与市场新闻）

- 流动性覆盖率 LCR、净稳定资金比率 NSFR：银行流动性监管指标  
- 压力情景下的现金流缺口分析：机构评估极端情况下能否履约  

## 4. 危机中的相互放大机制

```text
市场下跌 → 保证金追缴/强平 → 被迫抛售 → 加剧下跌（流动性螺旋）
          ↘ 信用债违约担忧上升 → 信用利差走阔 → 风险资产估值进一步承压
```

理解这一链条有助于解释「为什么下跌会加速」以及「为什么杠杆资金集中的板块跌起来更凶」。

## 5. 产品启示

- 个股风险提示应包含流动性代理指标（换手率、日均成交额/流通市值）  
- 融资融券/可转债相关建议必须提示信用风险来源  
- 组合层面应有「流动性分层」展示：多少仓位可快速变现、多少仓位变现成本较高
