# VaR 与 CVaR（预期损失）

> 一句话：VaR 给「损失门槛」，CVaR 给「越界后有多惨」；组合风控应同时看两者，并警惕危机时相关性上升。

## 1. VaR（Value at Risk）

在置信水平 \(\alpha\)（如 95%/99%）下，未来一段时间损失不超过的阈值。

例：1 日 95% VaR = 1 万元 → 大约只有 5% 的日子亏超 1 万（在模型假设下）。

### 常见估计

- 历史模拟  
- 参数法（方差-协方差，常假设正态）  
- 蒙特卡洛  

## 2. CVaR / Expected Shortfall

\[
\mathrm{CVaR}_\alpha = \mathbb{E}[L \mid L \ge \mathrm{VaR}_\alpha]
\]

- 对尾部更敏感  
- 更具「一致性」（含次可加性），监管与机构更偏好  
- Basel 体系亦强调 ES/CVaR 方向  

## 3. 实务陷阱

- 平静期估计在危机中失效（相关飙升、流动性消失）  
- VaR 不描述越界深度  
- 持有期与流动性期限要匹配  
- 需要压力测试与情景分析补充  

## 4. 产品启示

- 账户页展示：日/周 VaR、CVaR、相对风险预算剩余  
- 建议引擎：若新交易使 CVaR 超限 → 自动改为「减仓/观望」  
- 提供历史极端情景回放（如急跌月）
