# 调仓与再平衡

> 一句话：调仓是主动改变权重；再平衡是把漂移的权重拉回目标——两者都产生换手与税/成本，需要规则而非情绪。

## 1. 名词

| 词 | 含义 |
|----|------|
| 调仓 | 因观点/信号变化调整持仓 |
| 再平衡 Rebalancing | 恢复目标配置（固定权重、风险预算等） |
| 权重漂移 | 涨跌导致实际权重偏离目标 |
| 换手率 | 调仓剧烈程度代理 |
| 税收感知调仓 | 考虑税损收割等（视市场税制） |

## 2. 再平衡策略类型（下属）

| 类型 | 说明 |
|------|------|
| 日历再平衡 | 每月/季固定 |
| 阈值再平衡 | 偏离超 ± 才调 |
| 波动目标 | 组合波动超标则降仓 |
| 风险平价再平衡 | 维持风险贡献 |
| 信号驱动调仓 | 因子/模型排名变化 |

## 3. 成本与过拟合

- 调仓越勤，成本与滑点越高，夏普常被吃掉  
- A股还需 T+1、涨跌停导致「想调调不了」  
- 动态再平衡参数极易过拟合  

## 4. 与「加仓减仓建议」的关系

场景引擎的加减仓，本质是**目标权重 − 当前权重**的可执行差分，并受：

- 单票/行业上限  
- 换手预算  
- 风险限额  
- 可交易性  

## 5. 产品启示

- 用户可见「建议调仓清单」：标的、方向、数量区间、原因、预期换手  
- 提供「再平衡」与「观点调仓」两种模式标签
