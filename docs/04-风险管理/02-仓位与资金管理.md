# 仓位与资金管理

> 一句话：仓位决定生死；信号再好，错误的规模也会导致破产路径。

## 1. 常用仓位方法

| 方法 | 要点 |
|------|------|
| 固定分数 | 每笔风险占权益固定比例（如 0.5%–2%） |
| 波动倒数 / 目标波动 | 高波动低仓位 |
| ATR 止损仓位 | 按止损距离反推股数 |
| Kelly / 分数 Kelly | 最大化对数增长；全 Kelly 过猛，常用 1/4–1/2 |
| 风险预算 | 按策略/行业分配风险额度 |
| 金字塔加仓 | 趋势确认后递减加仓（与「越跌越买」相反） |

### Kelly 直觉

Kelly (1956) 原文最大化的是资本指数增长率 \(G=q\log_2(1+\ell)+p\log_2(1-\ell)\)，并证明全文押注会以概率 1 破产（PDF 见 `../99-参考文献/papers/`）。  
股票实务常用的离散式 \(f^* = (bp - q)/b\) 是后续把 \(\mathbb{E}[\log W]\) 用到二项赔率上的形式，不是 1956 文对 A 股的现成公式。  
估计误差大时必须收缩 → **分数 Kelly**（1/4–1/2）或更保守的固定分数。研衡开仓默认见 `10-以损定仓与A股手数.md`，不用全 Kelly。

## 2. 组合层硬限制（建议默认）

- 单票上限（如 10%–20%，按用户风险偏好）  
- 单行业上限  
- 总权益风险上限（日损/最大回撤熔断）  
- 相关持仓合并计量（一篮子同涨同跌）  
- 现金下限（机会与心态缓冲）  

## 3. 加仓 / 减仓专业原则

**更稳健的加仓**：趋势与基本面仍支持，且风险预算有余，且不加到违反集中度。  
**危险的加仓**：单纯因为浮亏而摊薄成本（可能是「接飞刀」）。  
**减仓触发**：达到目标区、风险预算耗尽、因子/逻辑失效、相关性冲击、流动性恶化。  

## 4. 产品启示

- 每条买卖建议必须带**建议仓位区间**与**最大可承受亏损金额**  
- 用户可设风险偏好档位，映射到分数与上限  
- 记录「计划仓位 vs 实际仓位」帮助行为纠正
