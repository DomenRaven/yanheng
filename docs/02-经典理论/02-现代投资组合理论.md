# 现代投资组合理论（MPT）

> 一句话：Markowitz 告诉我们——投资者交易的是「组合的风险收益」，不是单票故事；分散化降低非系统性风险。

## 1. 核心思想

- 资产收益有期望与协方差结构  
- 给定收益最大化风险，或给定风险最大化收益 → **有效前沿**  
- 组合方差：

\[
\sigma_p^2 = \sum_i \sum_j w_i w_j \mathrm{Cov}(r_i, r_j)
\]

## 2. 关键结论

- 单个资产「好不好」不如「加入组合后边际贡献」  
- 相关性越低，分散化收益越大；危机时相关性上升，分散化失效风险上升  
- 无风险资产引入后，形成资本市场线（与 CAPM 衔接）  

## 3. 实务局限

- 期望收益极难估准；误差被优化器放大（「误差最大化」）  
- 协方差也随时间变化（需收缩估计、因子风险模型）  
- 约束很重要：权重上下限、换手、行业暴露、不可卖空等  

## 4. 常见改进方向

- 风险平价 / 波动目标  
- Black-Litterman（把主观观点与均衡收益结合）  
- 稳健优化、CVaR 优化  
- 用因子模型压缩协方差维数（Barra 等）  

## 5. 产品启示

- 「加减仓」应在组合层考虑相关与集中度，而不是每票独立决策  
- 默认提供简单约束优化，而不是裸均值方差  
- 对散户：先做集中度与相关性体检，再谈精细优化
