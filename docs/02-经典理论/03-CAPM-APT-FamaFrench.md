# CAPM、APT 与 Fama–French 因子模型

> 一句话：资产定价模型回答「承担何种风险应获得何种期望收益」；它们是绩效归因与多因子投资的理论地基。

## 1. CAPM（资本资产定价模型）

\[
\mathbb{E}[R_i] = R_f + \beta_i \big(\mathbb{E}[R_m] - R_f\big)
\]

- \(\beta_i = \mathrm{Cov}(R_i, R_m)/\mathrm{Var}(R_m)\)  
- 只补偿系统性市场风险；特异风险不被定价  
- 优点：简洁；缺点：单因子解释力不足，假设强  

**用途**：估计合理期望收益、计算 Alpha、理解 Beta 暴露。

## 2. APT（套利定价理论）

多因子线性结构，基于无套利而非完整均衡：

\[
\mathbb{E}[R_i] - R_f = \sum_k \beta_{ik} \lambda_k
\]

- 因子可以是宏观（通胀、利率）或统计/特征因子  
- 灵活但「选哪些因子」本身是难题  

## 3. Fama–French 三因子 / 五因子

在市场因子外增加风格：

**三因子**：Market、SMB（小盘减大盘）、HML（高账面市值比减低）  

**五因子**：再加 RMW（盈利）、CMA（投资）  

经验上，对分散组合收益截面的解释力显著高于纯 CAPM（文献常引用约大幅提升解释比例，具体视样本而定）。

争议：溢价是风险补偿还是错误定价？对产品不关键——关键的是**能否稳定度量暴露与归因**。

## 4. 与 A 股多因子实务的关系

- 学术 FF 因子是「收益解释」；国内金工常用价值、动量、质量、流动性、波动等扩展  
- Barra 类模型把行业 + 风格暴露结构化，服务风险预测与组合约束  
- Alpha 因子与风险因子会转化：被用滥的 Alpha 往往变成风险  

## 5. 产品启示

- 持仓与建议应展示：**市场 Beta、风格暴露、行业暴露**  
- 绩效用多因子归因，避免把运气当能力  
- 「预测模块」输出最好能翻译成因子语言，便于风控对接
