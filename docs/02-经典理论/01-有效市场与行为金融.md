# 有效市场假说与行为金融

> 一句话：EMH 解释「为什么很难稳定战胜市场」；行为金融解释「人为什么系统性犯错」——产品应同时尊重两者。

## 1. 有效市场假说（EMH）

Fama 等提出：价格在不同程度上反映可得信息。

| 形态 | 信息集合 | 含义 |
|------|----------|------|
| 弱式 | 历史量价 | 纯技术分析难获稳定超额 |
| 半强式 | 公开信息 | 公开财报/新闻难稳定超额 |
| 强式 | 全部信息（含内幕） | 理论极限；内幕交易违法 |

### 对产品的含义

- 不要承诺「稳定战胜市场」  
- 可追求的是：更好的风险调整、更少行为错误、在特定低效环节的**阶段性**边缘  
- 任何 Alpha 都可能衰减（被交易掉）  

## 2. 行为金融常见偏差

| 偏差 | 表现 | 产品可干预点 |
|------|------|--------------|
| 过度自信 | 交易过频、仓位过大 | 冷静期、仓位上限 |
| 处置效应 | 锁盈放亏 | 计划止盈止损提醒 |
| 损失厌恶 | 该止损不止 | 规则化退出 |
| 羊群 | 追热点 | 拥挤度/估值警示 |
| 锚定 | 死守成本价 | 以风险而非成本决策 |
| 赌徒谬误 | 「跌多了该涨」 | 概率教育 |

## 3. 市场何时可能低效

- 散户主导、制度摩擦、信息传播慢  
- 流动性危机、极端情绪  
- 结构性限制（涨跌停、融资融券约束）  
- 另类数据尚未被充分定价（窗口短暂）  

## 4. 产品启示

- 建议引擎加入「行为护栏」与「拥挤度」  
- 展示基准对比与风险调整收益，抑制绝对收益幻觉  
- 对用户解释：边缘来自概率优势 + 风控，不是神谕
