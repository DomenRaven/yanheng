# 交易心理学专论

> 一句话：行为金融解释「市场平均人会错在哪」；交易心理学落实到「你个人账户如何少踩这些坑」。

## 1. 与已有文档关系

- 宏观理论见：`01-有效市场与行为金融.md`  
- 本文补齐：**下属偏差机制、情绪周期、账户级干预设计**（产品要用）

## 2. 核心偏差（下属概念）

| 偏差 | 市场表现 | 账户干预 |
|------|----------|----------|
| 过度自信 | 过频交易、过大仓位 | 频率上限、仓位模板 |
| 损失厌恶 / 处置效应 | 锁盈放大亏 | 计划止损优先于成本价 |
| 锚定 | 死守成本、前高前低 | 以风险与逻辑决策 |
| 羊群 / FOMO | 题材高潮追入 | 拥挤度与生命周期提示 |
| 确认偏误 | 只看多头理由 | 强制列出反方证据 |
| 赌徒谬误 | 「跌多了该涨」 | 概率与独立事件教育 |
| 心理账户 | 不同仓位不同纪律 | 统一风险预算 |
| 沉没成本 | 因为已亏而加仓 | 禁止「仅因浮亏」加仓 |

## 3. 情绪周期（平级框架）

乐观 → 兴奋 → 亢奋 → 否认真理 → 恐惧 → 绝望 → 冷静 → 机会感……  
可与主题生命周期、波动率区制联立。

## 4. 与博弈、盘口的交界

- 主力/游资策略常利用散户偏差（诱多诱空）  
- 产品应把「情绪指标」与「订单流」分开展示，避免互相污染
