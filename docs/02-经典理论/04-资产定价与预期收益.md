# 资产定价、预期收益与「可交易 Alpha」

> 一句话：模型给出的是期望与风险结构；真正能用的是扣除成本、约束与衰减后的可交易边缘。

## 1. 从「预测」到「可交易 Alpha」

一条信号要成为产品可用能力，至少通过：

1. **统计显著性**：IC、RankIC、t 值、衰减曲线  
2. **经济显著性**：扣除成本后仍有边缘  
3. **可执行性**：涨跌停、停牌、流动性、T+1  
4. **稳健性**：多时段、多市况、子样本  
5. **容量**：资金变大后是否消失  
6. **可解释/可监控**：知道它为何失效  

## 2. 预期收益估计的残酷现实

- 均值比波动更难估；优化器对均值误差极敏感  
- 实务常：**对风险估计更信任，对收益估计更保守**（收缩、贝叶斯、Black-Litterman）  
- 排序（相对强弱）往往比绝对价格预测更有用  

## 3. 评价预测的正确指标

| 场景 | 更合适指标 | 不太合适 |
|------|------------|----------|
| 选股排序 | IC / RankIC / IR | 单纯准确率 |
| 回归预测 | IC、分层多空收益 | 只看 MSE |
| 交易策略 | 夏普、卡玛、最大回撤、换手 | 只看累计收益 |
| 分类涨跌 | 概率校准、损益加权 | 忽略交易成本的 Accuracy |

## 4. Alpha 衰减

公开数据 + 同质逻辑 → 边缘被交易掉。现代研究亦提示：LLM 可能加速可复制 Alpha 的衰减。  
产品策略：强调**差异化数据/工程/风控/体验**，而非单一神秘公式。

## 5. 产品启示

- UI 避免「明日上涨概率 87%」这种过度精确（除非有校准证明）  
- 用「相对吸引力分层 + 风险预算」代替点预测神谕  
- 内建衰减监控：IC 下滑自动降权或停用
