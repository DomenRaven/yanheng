# 财务造假识别与风险红旗清单

> 一句话：识别财务异常不是抓「铁证」，而是积累「红旗」——单个信号可能是巧合，多个信号叠加应大幅提高警惕并降低仓位或回避。

## 1. 常见造假/激进会计手法

| 手法 | 表现 |
|------|------|
| 虚增收入 | 提前确认收入、关联方虚假交易、渠道压货 |
| 虚增利润 | 费用资本化、坏账计提不足、公允价值调节 |
| 隐藏负债 | 表外融资、担保未披露 |
| 商誉/资产减值递延 | 该减值不减，集中在业绩差年份「大洗澡」 |
| 现金流粉饰 | 经营现金流与投资/筹资现金流科目腾挪 |

## 2. 红旗清单（Red Flags）

| 类别 | 红旗信号 |
|------|----------|
| 收入质量 | 收入增速远超行业、应收账款增速持续快于收入 |
| 利润质量 | 净利润与经营现金流长期背离 |
| 资产质量 | 存货/在建工程/其他应收款异常膨胀 |
| 治理 | 审计师频繁变更、财报多次延迟、独立董事频繁辞职 |
| 股权/资金 | 大股东高比例质押、频繁减持、关联交易占比高 |
| 外部信号 | 供应商/客户高度集中且难以验证、突击更换会计师事务所 |
| 估值背离 | 业绩持续「精准达标」但现金流始终吃紧 |

## 3. 分析流程（产品可模板化）

```text
1. 计算经营现金流/净利润比率的多年趋势
2. 检查应收账款、存货周转天数是否持续恶化
3. 检查商誉占净资产比例与历史减值记录
4. 检查审计意见类型（是否非标）
5. 检查股权质押比例与解禁/减持计划
6. 交叉行业地位：收入增速是否显著偏离同行
7. 汇总红旗数量 → 输出风险等级，而非「确定造假」结论
```

## 4. 输出原则（合规与严谨）

- 只能输出「风险信号/概率性警示」，**不得断言「财务造假」**（涉及法律定性）  
- 多红旗叠加 → 建议：降低仓位权重、要求更高的安全边际、或直接排除入选股票池  
- 结合监管处罚公开信息（如有）作为客观佐证，而非主观推测  

## 5. 产品启示

- 基本面模块内置「财务风险红旗计数器」，作为选股负向过滤器  
- 红旗较多的标的即使技术面/题材面强势，也应在建议中明确提示财务风险
