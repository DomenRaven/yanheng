# 绝对估值：DCF 与 DDM

> 一句话：绝对估值不看别人怎么定价，只问「这家公司未来能创造多少现金，值多少钱」；结果对假设极度敏感，必须敏感性分析而非迷信单一数字。

## 1. DCF（现金流折现）

\[
EV = \sum_{t=1}^{n} \frac{FCF_t}{(1+WACC)^t} + \frac{TV}{(1+WACC)^n}
\]

| 组件 | 说明 |
|------|------|
| FCF（自由现金流） | 常用 FCFF（企业自由现金流）或 FCFE（股权自由现金流） |
| WACC | 加权平均资本成本，股权成本（常用 CAPM）与债务成本按资本结构加权 |
| TV（终值） | 永续增长法：\(TV = FCF_n(1+g)/(WACC-g)\)；或退出倍数法：\(TV = EBITDA_n \times \text{倍数}\) |
| g | 永续增长率，不应超过长期名义 GDP 增速（常用 2%–3%） |

### 关键纪律

- **敏感性分析是标配**：WACC 变动 1%，估值可能变动 20% 以上  
- **终值占比过高（常见 >60%–70%）是警报**：说明估值主要在赌远期，而非近期可验证的现金流  
- 增速与利润率是两个自由参数，容易被建模者「调节」得出想要的结论 → 需与 EVA/ROIC 框架自洽校验（见 `03-EVA与护城河财务验证.md`）  
- FCFF 用 WACC 折现得企业价值（EV），减净债务、加过剩现金 = 股权价值；FCFE 直接折现得股权价值，两者应交叉核对  

## 2. DDM（股利贴现模型）

\[
P_0 = \sum_{t=1}^{\infty} \frac{D_t}{(1+r)^t}
\]

- 戈登增长模型（稳定增长）：\(P_0 = D_1 / (r - g)\)  
- 适用：分红稳定、成熟、低留存再投资的公司（银行、公用事业、高股息蓝筹）  
- 局限：对不分红或低分红成长股（多数科技/新能源）不适用；增长率极度敏感  

## 3. 方法选择决策树（实务）

```text
成熟稳定型（消费/公用事业/银行）
├── 高分红 → DDM
└── 低分红 → DCF + PE-Band

高成长型（科技/医药/新能源）
└── DCF（分阶段增长）+ PEG + PS

周期型（煤炭/钢铁/有色）
└── PB + EV/EBITDA（避免用 PE，周期顶部/底部利润失真）

多元化集团
└── SOTP（分部加总估值）

尚未盈利
└── PS / EV/Sales（配合现金消耗速度评估）
```

## 4. 产品启示

- 绝对估值模块必须输出：**假设清单（g、WACC、预测期）+ 敏感性表格 + 终值占比**  
- 严禁只显示单一「目标价」而不披露假设  
- 与相对估值交叉校验，差异 >30% 需显式提示「假设分歧」
