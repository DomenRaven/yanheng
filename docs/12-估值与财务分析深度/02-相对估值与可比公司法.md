# 相对估值与可比公司法

> 一句话：相对估值回答「和同类比，贵不贵」；简单快速但依赖「真可比」的前提，单一倍数容易被资本结构和会计政策扭曲。

## 1. 常用倍数

| 倍数 | 公式 | 适用 | 局限 |
|------|------|------|------|
| PE | 股价/EPS | 盈利稳定公司 | 忽略资本结构、周期顶底失真 |
| PB | 股价/每股净资产 | 金融、重资产、周期股 | 不反映盈利能力差异 |
| PS | 股价/每股营收 | 未盈利/高成长公司 | 忽略成本结构与利润率 |
| EV/EBITDA | 企业价值/EBITDA | 资本密集、跨资本结构比较 | 忽略资本开支差异 |
| PEG | PE / 盈利增速 | 成长股粗筛 | 增速预测误差大，<1 未必真便宜 |
| EV/Sales | 企业价值/营收 | 未盈利成长公司 | 与利润率脱节 |

## 2. 可比公司选择纪律

- 同行业 + 同规模量级 + 同发展阶段（禁止把龙头 PE 直接套用到小公司）  
- 同会计准则/口径（是否含非经常性损益、是否 TTM）  
- 同商业模式（重资产 vs 轻资产不可比 PE）  
- 至少 3–5 家可比公司，取中位数而非均值（避免极端值扭曲）  

## 3. PE-Band / PB-ROE 方法

- **PE-Band**：把当前 PE 放入历史 PE 分位区间，判断相对自己历史的贵贱  
- **PB-ROE**：高 ROE 应享受高 PB 溢价；若 PB 高但 ROE 未同步走高，警惕估值透支  

## 4. 可比交易分析（并购视角）

- 用历史并购交易的倍数（含控制权溢价）评估潜在被收购价值  
- 适合壳资源、资产注入、国企改革等特殊事件场景  

## 5. 常见估值陷阱

| 陷阱 | 说明 |
|------|------|
| 低 PE 陷阱 | 可能是盈利周期顶点或行业结构性衰退 |
| 高 PE 陷阱 | 可能是一次性利润暴跌导致分母失真 |
| 龙头溢价滥用 | 小公司不该套龙头估值 |
| 忽略成长质量 | 高 PEG 未必差，若增长可持续且资本效率高 |
| 会计口径不一致 | 未剔除非经常性损益直接比较 PE |

## 6. 产品启示

- 展示估值分位（历史 + 同行）而非单一倍数结论  
- PB-ROE 散点图适合做「贵不贵、值不值」的可视化  
- 与绝对估值（DCF）交叉验证，差异过大需归因
