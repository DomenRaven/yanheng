# 杜邦分析与三大报表深度解读

> 一句话：ROE 高不高只是结论，杜邦拆解告诉你「钱是怎么赚的」——靠周转、靠利润率还是靠杠杆，决定了这份高回报能不能持续。

## 1. 杜邦分析拆解

\[
ROE = \underbrace{\frac{\text{净利润}}{\text{营业收入}}}_{\text{净利率}} \times \underbrace{\frac{\text{营业收入}}{\text{总资产}}}_{\text{资产周转率}} \times \underbrace{\frac{\text{总资产}}{\text{股东权益}}}_{\text{权益乘数（杠杆）}}
\]

| 驱动 ROE 的方式 | 含义 | 可持续性 |
|------------------|------|----------|
| 高净利率驱动 | 定价权/品牌/成本优势 | 通常更可持续 |
| 高周转驱动 | 运营效率、薄利多销 | 依赖规模与管理 |
| 高杠杆驱动 | 借债放大回报 | 风险最高，危机中先垮 |

**同样 ROE=20%，杠杆驱动的公司风险远高于净利率驱动的公司**——这是散户最容易忽略的一层。

## 2. 三大报表交叉验证

| 报表 | 核心问题 | 常见陷阱 |
|------|----------|----------|
| 利润表 | 赚了多少账面利润 | 非经常性损益、会计估计变更 |
| 资产负债表 | 家底与负债结构 | 商誉堆积、存货/应收异常增长 |
| 现金流量表 | 利润是否变成真钱 | 经营现金流长期低于净利润 |

### 关键交叉检查

- 净利润高但经营现金流持续低迷 → 利润「纸面化」风险（应收账款/存货压库存）  
- 利润增长但经营现金流为负 → 需追问原因（快速扩张 vs 造假）  
- 资本开支持续远超折旧 → 关注是否为维持性还是扩张性投入（影响自由现金流估算）  

## 3. 高频关注科目

| 科目 | 关注点 |
|------|--------|
| 应收账款周转 | 变慢可能意味着渠道压货或收入确认激进 |
| 存货周转 | 变慢可能意味着需求转弱或产品滞销 |
| 商誉 | 并购频繁的公司需关注减值风险 |
| 其他应收款 | 异常大额需警惕关联方占款 |
| 经营性现金流/净利润比 | 长期显著小于 1 需警惕 |

## 4. 产品启示

- 基本面模块的 ROE 展示必须附带杜邦三因子拆解，而不是单一数字  
- 财务健康度评分应包含「现金流质量」子项（经营现金流/净利润）  
- 三大报表联动异常应触发风险旗标，提示进一步核查
