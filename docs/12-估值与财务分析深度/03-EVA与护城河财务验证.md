# EVA、剩余收益与护城河的财务验证

> 一句话：EVA 回答「公司赚的钱是否超过了资本成本」——不超过就是「增长价值毁灭机」；护城河不能只靠定性故事，要用财务趋势验证。

## 1. EVA（经济增加值）

\[
EVA_t = NOPAT_t - WACC \times \text{投入资本}_{t-1}
\]

- NOPAT：税后净营业利润  
- 若 EVA 长期为负：即使收入利润在增长，也是在「烧资本」而非创造价值  
- 内生增长率：\(g = RR \times ROIIC\)（再投资率 × 新增投资资本回报率）  
  - 若目标增速 10%，ROIIC 仅 12%，意味着需要再投资约 83% 的利润 → 自由现金流所剩无几  
  - EVA 框架强迫「增速」与「利润率」两个假设自洽，防止 DCF 建模者随意设参数  

## 2. EPV（零增长永续价值）与护城河验证

\[
EPV = \frac{\text{常态化盈利}}{\text{资本成本}}
\]

- 常态化盈利：剔除非经常性损益，加回超出维持性资本开支的「成长型资本开支」  
- 用 **EPV / 调整后净资产** 的多年趋势判断护城河：  
  - ≈ 1：基本无护城河（盈利仅覆盖资本成本）  
  - < 1：可能在毁灭价值  
  - ≫ 1 且长期稳定：存在真实、可持续的竞争优势  

## 3. 护城河的定性框架（与财务验证配合）

| 来源 | 例子 |
|------|------|
| 无形资产/品牌 | 定价权、客户忠诚度 |
| 转换成本 | 企业软件、金融系统 |
| 网络效应 | 平台型公司 |
| 成本优势 | 规模、专有工艺、地理位置 |
| 有效规模 | 区域自然垄断（小市场大玩家） |

**验证纪律**：定性护城河故事 + EVA/EPV 长期为正且稳定 → 更可信；只有故事没有财务印证 → 降权重。

## 4. 波特五力（竞争格局定性工具）

供应商议价力、购买者议价力、潜在进入者威胁、替代品威胁、行业内竞争强度 —— 五力弱意味着行业结构性利润空间更大，为护城河提供中观佐证（与 `01-基础概念/05-产业面与行业分析.md` 呼应）。

## 5. 产品启示

- 财务健康度评分应包含 EVA 是否为正、ROIC-WACC 差值趋势  
- 「护城河评分」应强制关联至少 3 年 EPV/净资产 走势，而非仅文字描述  
- 增长股必须展示「维持增长所需的再投资强度」，防止对高增长盲目乐观
