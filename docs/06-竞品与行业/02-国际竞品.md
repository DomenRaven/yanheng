# 国际竞品与对标

> 一句话：国际顶尖是「数据+工作流+AI 代理」；开源侧是「可复现的研究到交易引擎」。

## 1. 机构终端与数据

| 产品 | 启示 |
|------|------|
| Bloomberg Terminal + ASKB | 对话式/代理式研究，答案可追溯到数据查询语言 |
| FactSet Quant | 从想法到回测/优化的量化工作流与海量数据集 |
| Refinitiv 等 | 数据与分析管线 |

启示：AI 要挂在可信数据与可验证查询上，而不是自由发挥。

## 2. 算法交易与研究平台

| 产品 | 启示 |
|------|------|
| QuantConnect（LEAN + Mia） | 研究/回测/优化/实盘一体；AI 助手进入策略生命周期 |
| WorldQuant Brain 等 | 众包/表达式 Alpha 研究文化 |
| TradingView | 极致图表与社区脚本（偏技术分析体验） |

## 3. AI 量化框架

| 项目 | 启示 |
|------|------|
| Microsoft Qlib | 工业级 AI 量化流水线开源参考 |
| 学术模型（Transformer/GNN/LLM-Alpha） | 预测模块可演进，但不能跳过组合与风控 |

## 4. 对本产品的直接借鉴

- **Agent 输出附带可复现计算**（类似 BQL 代码思路的「可审计步骤」）  
- **研究→回测→监控**同一对象模型  
- **AI 助手服务投研流程**，而不是只聊股票传闻  
- 开源引擎可作后端，产品力做在场景建议与体验
