# 国内竞品与对标

> 一句话：国内已是「行情入口 + 社区 + 量化平台 + 券商终端」分层市场；新进者应避开全能战争，咬住场景化决策与可解释风控。

## 1. 分层地图

| 层级 | 代表 | 核心能力 |
|------|------|----------|
| 大众行情/资讯 | 同花顺、东方财富 | 行情、资讯、简单选股、部分 AI |
| 社区/内容 | 雪球 | 观点、跟单氛围、情绪 |
| 量化研究平台 | 聚宽、米筐、优矿、BigQuant | 数据、回测、因子、社区策略 |
| 券商量化/实盘 | 同花顺 SuperMind、QMT/PTrade 等 | 研究到交易闭环 |
| 机构数据终端 | Wind、Choice | 全市场深度数据 |

## 2. 重点对标

### 同花顺 / SuperMind

- 优势：流量、数据广度、i问财自然语言、量化到实盘叙事完整  
- 弱点（机会）：个性化账户状态机与「专业建议可解释性」对散户仍可加强  

### 东方财富

- 优势：资讯与基金流量、生态闭环  
- 机会：深度量化决策层不是其唯一重心  

### 雪球

- 优势：信任关系与内容；AI/情绪分析  
- 机会：系统化风控与严格回测工具不是主业  

### 聚宽

- 优势：量化教育与社区、Python 友好、模板多  
- 限制：免费额度/高级数据；偏研究平台而非「持仓场景顾问」  

### 米筐

- 优势：RQData/RQFactor/RQAlpha/RQOptimizer 更机构化  
- 定位：专业用户；个人产品体验与教育向辅助空间仍在  

## 3. 可借鉴能力清单

- 自然语言选股（问财类）  
- Notebook 研究环境  
- 因子检验标准化报告  
- 组合优化器与风险模型  
- 社区策略分享（注意同质化与衰减）  
- 模拟盘到实盘的路径  

## 4. 差异化切口（建议）

1. **持仓状态机驱动的建议**（竞品多是选股/看盘）  
2. **冲突解释**（技术 vs 基本面 vs 风险）  
3. **行为金融护栏**（降过度交易）  
4. **回测假设透明**（反营销话术）  
5. **中低频可解释 Alpha + 强风控**，而非高频军备
