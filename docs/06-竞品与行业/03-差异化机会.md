# 差异化机会与战略建议

> 一句话：不要做成「又一个行情 App」；做成「懂你账户状态的可解释投研副驾」。

## 1. 市场空白（相对竞品）

| 空白 | 说明 |
|------|------|
| 账户状态一等公民 | 多数工具强于选股弱于「我现在该不该加仓」 |
| 建议冲突管理 | 少有产品把多信号冲突当作正式 UX |
| 透明回测假设 | 营销型 AI 荐股相反方向 |
| 行为护栏 | 减少追涨杀跌，而不只是给更多信号 |
| 中文场景话术 + 量化严谨 | 两者兼顾的少 |

## 2. 不建议的战争

- 与同花顺拼行情完整度  
- 与 Wind 拼数据广度  
- 与顶级私募拼延迟与高频  
- 与雪球拼社区内容量  

## 3. 建议的护城河路径

1. **决策状态机 + 风控模板**（产品独特数据：用户行为与账户轨迹）  
2. **可解释因子库与衰减监控**（信任）  
3. **高质量教育内容结构化**（获客与留存）  
4. 后期再接持牌投顾/券商通道（合规扩展）  

## 4. 风险

- 监管对荐股/程序化趋严  
- Alpha 公共化导致边缘变薄  
- 用户把工具当许愿机导致口碑风险  
- 数据成本与版权
